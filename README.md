# 大国崛起 · 山海防线

原创、开源的三维即时战略游戏，主要面向桌面浏览器。**2.0** 以侦察、护航、登陆、接管和持续补给为核心：运输抵达才有收入，受损设施可以恢复，撤离与保全部队也能赢得任务。

**[国内官网](https://www.daguojueqi.site/) · [单机与双人试玩](https://www.daguojueqi.site/play/) · [下载中心](https://www.daguojueqi.site/downloads/) · [2.0 发行页](https://github.com/chencheng666/great-powers-rts/releases/tag/v2.0.0) · [问题与建议](https://github.com/chencheng666/great-powers-rts/issues)**

![深蓝生命线舰队与岛礁实机](docs/releases/v2.0.0-images/deepblue-command.png)

> 非官方《红色警戒》续作，不使用其代码、模型、音乐或配音。现实装备名称仅用于原型资料介绍；战役架空，数值经过游戏化处理，不代表真实军事性能。国产坦克、舰船为自有简化模型；本版接入的社区资产按原许可分别署名。

## 直接开玩

- **网页：**打开国内试玩，输入昵称即可进入单机；联机由一人创建房间，另一人输入六位房间码，双方准备后开始。
- **离线：**下载免安装 ZIP，完整解压后打开 `PLAY.html`。模型、地面材质、音乐和中文男女声都在包内，不需 Node.js；离线文件不包含对战服务器。
- **桌面：**下载页按平台和架构列出已实际生成的 Tauri 安装包。Mac 未公证、Windows 未签名；麒麟/UOS 需具体硬件验证，暂不支持龙芯、申威。
- **升级：**先在游戏内分别导出战局、荣誉和挑战成绩。不同域名、浏览器、桌面应用的本地存储互不相通。

## 怎么打好一局

1. **先侦察再推进。**地面视野、空中侦察、雷达和声呐各司其职；炮兵需要可见目标，电子干扰不能代替防空或反导。
2. **守住保障。**常规战区以运输收入为主，月表保留采矿；补给车提供范围补弹与付费维修，飞机返场、舰艇和潜艇返港整备。
3. **混合编组。**装甲掩护工程师和运输，防空保护远程火力，侦察防止绕后。不要把全部资金变成一种装备。
4. **按任务取舍。**接管不等于永久收益：设施必须完整、通电且不被争夺。保护目标、有效交付和损失会影响评价。

核威慑仅在“战略纵深”自选开启，默认关闭，双人需双方确认。发射有前置设施、费用、冷却、次数和公开倒计时；准备期可打断，末段需雷达、供电、弹药与反导覆盖。普通防空不能替代反导，分散与疏散同样重要，打击包含友伤。详见 [装备档案](EQUIPMENT.md)。

## 性能边界

在 Apple M1 Pro、Ego Chromium、1280×720 窗口、标准画质下，240 单位陆战帧耗时 P50/P95 为 **24.5/32.5 ms**，陆海混编为 **32.0/43.6 ms**。每组热身 3 秒、采样 12 秒；游戏画布为 956×662、像素比 1。合批使对照场景绘制次数减少约七成，但不是所有设备的 60 帧保证。

高画质偏向细节，大军团优先选标准。更多分辨率、长局、弱网和国产显卡仍需持续测试。[完整条件与对照](docs/releases/v2.0.0.md#性能记录)

## 源码运行

需要 Node.js 22.16+ 和支持 WebGL 2 的桌面浏览器。运行已有模型不需要 Blender。

```bash
git clone https://github.com/chencheng666/great-powers-rts.git
cd great-powers-rts
npm ci
npm run dev
```

局域网联机需运行同一个主机服务，其他电脑访问启动日志里的局域网地址：

```bash
npm run build
npm run server:lan
```

仅向可信局域网开放端口；公网请使用 HTTPS/WSS。详见 [部署说明](docs/联网对战与部署说明.md) 和 [桌面兼容说明](docs/桌面版构建与兼容性.md)。

## 技术架构

**JavaScript ES Modules + Three.js + Vite + Node.js / WebSocket + SQLite + Tauri 2**。单机和服务端复用模拟规则，联机由服务器决定资源、命中、归属与胜负，客户端负责输入、快照插值和表现。

| 层次 | 代码入口 |
| --- | --- |
| 模拟、AI、存档 | `game.js`、`tactical-ai.js`、`savegame.js`；寻路使用 PathFinding.js |
| 战区与任务 | `theater-maps.js`、`theater-data.js`、`theater-operations.js`，共享占领、修复、撤离与能源规则 |
| 运输与补给 | `maritime-logistics.js`、`logistics-economy.js`、`modern-combat.js` |
| 模型与绘制 | `render.js`、`army-batches.js`、`domestic-models.js`、`personnel-models.js`、`open-assets.js` |
| 联网与安全 | `server/index.mjs`、`commands.mjs`、`battle-view.mjs`；按席位过滤迷雾、校验权限，双人/六方数据隔离 |
| 交付 | 内置中文语音与 Web Audio、离线打包、Tauri 桌面封装、GitHub Actions、多版本回退 |

```bash
npm test
npm run build
npm run package:offline
node scripts/verify-theater-missions.mjs
```

自动化覆盖规则、存档、货运去重、海陆通行、任务、联机和模型预算。自动通关、浏览器画面、实际联网、完整下载校验分别记录，不把构建成功当成所有平台都能流畅运行。
