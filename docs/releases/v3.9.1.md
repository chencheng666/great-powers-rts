# 3.9.1：空海补给经济

构建 `20261116-convoy-r1`。雪岭入海新局取消采矿，旧采矿存档保留原经济、矿车及已装载货物。历史战区、独立科幻版和联机规则不变。

## 经济与电脑

- 新局不生成矿区与矿车，不能采购矿车；开局仍为4200资金。空运每批720、海运每批900，成功卸货才到账。最短班次间隔36/60秒，上一班离场后再放行；断电、受袭或堵泊会延迟交付。
- 空运前往仓库，仓库全部损失后改送指挥中心，每批降为180。港口全部损失后海运撤出；运输途中被击毁，只损失尚未交付的物资。
- 六座油井及物资箱、设备回收场、能源仓争夺保留。油井每座11资金/秒，资源点沿用有限库存；信标提供视野和争夺积分。
- 运输从真实地图边缘驶入：上中游港口沿上游河道进场，南部港口从外海进入；空运按接收基地选择地图边缘。不同位置的航程会影响实际周转速度。
- 经济货运与部队增援独立排程，互不堵住空运卸货；补给船不占六个战斗舰艇编制泊位，经济载具不占前线部队人口。旧档积压货船仍按原规则排队。
- 电脑停止采购矿车，为维修补弹保留600资金，并降低非必要扩建支出；工程师优先争夺附近油井与仍有库存的能源仓，飞机和舰队护送载货单位。补给线受袭需先侦察到威胁才转入防守，护航不覆盖返场、装载和整备命令。
- 战术面板显示空运/海运当前状态、累计交付及运输损失，注明仓库损失后的应急金额。
