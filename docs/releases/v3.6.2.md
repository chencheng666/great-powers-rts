# 3.6.2：程序化设施、舰队辨识与下载更新

构建号：`20261112-procedural-facilities-r1`。本轮继续使用代码生成模型；发布、安装包与线上回读结果在完成后补充，不以候选包代称已上线。

## 玩家反馈

- 机场：移除旧的高架停机坪和导航灯，程序化长跑道与机坪分开配色，保留六个与调度坐标一致的机位。铺装逐顶点贴合当前地形，停机高度使用相同表面参数。跑道长度从13.8增至25.2本地模型单位，不扩大建筑碰撞或改写起降调度规则。树冠投影净空覆盖跑道延长段和机坪边缘。
- 码头：缩小仓库，扩展沿岸装卸平台，三台吊机、24个分层集装箱突出装卸用途。纯程序化版本8个合批网格、4248个三角形，仍在原6000三角形预算内；已有开放港机到达时复用其几何和材质。
- 潜艇：已知潜航轮廓不再被不透明海面遮挡，己方轮廓和水面识别标记保持清楚。敌艇仍须通过战争迷雾、声呐与现有可见性判定，未侦察到的敌艇不创建显示模型；不改隐形或探测规则。
- 音效：空中声源按实际模型投影定位，避免地面投影离屏造成静音。四条移动声部上限内，为可听见的空军、海军保留声部，避免地面类别先占满；适度增强喷气、舰艇、潜航和发动机声，保留静音、衰减、合批及停止清理。
- 入口：教程明确只在灰谷入门提供，月表与现代架空战场分开说明。保留对地飞机和现有反制关系；没有依据一条建议直接删除整类兵种或把架空地图标成现实作战模拟。
