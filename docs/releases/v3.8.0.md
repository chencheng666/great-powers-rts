# 3.8.0：雪岭入海

新增一张 7680 × 5760 主地图。北部雪岭与针叶林沿河谷过渡到草地、芦苇湿地和海湾，东部背风区为沙砾戈壁。两岸大陆由三座桥连接，上游河道与外海连续通航，河口港岛可登陆。

默认一名玩家与五个独立电脑阵营。每方有基地、两辆矿车、初始陆军、工程师、海港与巡逻舰。电脑分别采矿、扩建、侦察、争夺信标并发展空军和舰队，独立思考时间错开。地理上不强求镜像对称，采用等量初始资源与相同基础编制。

模型、山体、地貌权重、植被、芦苇、材质和风雨海浪声音由程序规则生成。模型与材质生成后复用；运行时更新区域雨雪、云影与环境混音。雨雪是区域表现，本版没有新增天气减速或视野惩罚。

主入口集中推荐“雪岭入海”，教学、历史战区、原双人联机和六方实验入口保留。新地图先支持单机六方，不扩展现有联机协议。旧战局仍按其原地图恢复，原版退役兵种规则保持有效。
