# 2.0.2 指挥官征途

本版将 10 月 28 日网页改进同步到桌面与离线包，游戏规则和奖励保持一致。

- 独立灰谷入门战区、新兵起始资金与支援编队、玩法选择指引。
- 受损冒烟、修复消烟与命中特效；保留武器及移动音效、航母甲板滑行等已实现功能。
- 首胜青铜、挑战紫晶、三胜基地功勋标识；三胜且在两个战区获胜解锁青玉与先锋试炼。

- 文字必填、图片可选的意见反馈；必要错误及匿名游玩时长上报。

## 升级与平台边界

成长和存档保存在本机。升级前分别导出战局与荣誉；跨浏览器和跨设备不自动同步。
奖励涂装与基地标识只改变普通单机外观，不增加战力，既有地图继续开放。
ZIP 完整解压后打开 PLAY.html，可断网单机；反馈与匿名时长统计需要联网。
Mac 未公证，Windows 未签名；Linux 需要 WebKitGTK 4.1、GTK3 和支持 WebGL2 的图形环境。
CI 构建不代表全部系统或硬件实测；统信 UOS、麒麟尚无本轮实机验收证据，不宣称认证通过。
