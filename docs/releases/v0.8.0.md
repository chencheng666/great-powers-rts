## 主要升级

- 动作：人物腰部瞄准、持枪后坐、按实际位移推进步态；主战坦克独立炮管后坐与近景循环履带。玻璃、金属、橡胶材质区分，远景人物按关节合批。
- 联机：位置、车体与炮塔逐帧插值，后坐独立于服务器快照频率；修复房间码加入及等待、错误提示。战斗判定仍在权威服务端。
- 海军：六类连续舰体，运输机比例、港口浮航、潜航遮挡与艇首鱼雷出管转向优化。舰艇右键己方港口可指定维修补弹；不同港口独立分配泊位，维修仍需资金、供电、停稳和脱战。
- 后勤：同侧同类空运／海运只保留一班在途，前班退出后才发下一班；旧存档积压载具进入等待队列。运输可遭拦截，收入不是固定周期保底。
- 策略：AI 按已侦察威胁补充反制装备，在造部队计入配额，重伤和缺弹单位撤回真实设施付费整备，遵守双方同样的科技和资源条件。
- 复盘：单机和联机结束后展示十三项对比指标及最近关键战损，统计随存档保存；联机战斗中不公开敌方统计。
- 共创功能：图鉴、八阶荣誉与金属徽章、功勋与胜利奖励、进度备份，首页对齐与敌我辨识，人物、坦克、舰船、设施和地表细化。肩章重设计仍为提案，不重置玩家积分。
- CAI 建议：七图纵深、资源回收与占领、路线虚线、间谍定时破坏与工程师拆弹、可反制的游戏内网络压制、中文女声、建筑完工后手动部署等均收录。

## 双人联机与局域网

离线文件本身不包含对战服务，不能直接加入联网房间。局域网主机使用 v0.8.0 完整源码和 Node.js 22.16+，运行 `npm ci`、`npm run build`、`npm run server:lan`；其他玩家打开启动日志中的局域网地址。两名玩家使用不同设备或独立浏览器身份，支持昵称游客、六位房间码、双方准备后开战。

公网测试入口：http://43.135.186.21:8088/

该服务器位于硅谷，2026-10-09 已同步 v0.8.0 网页与对战服务，战绩备份后保留。公网已实测加入房间、双方准备开战、移动指令、战后复盘及单机存档恢复。国内下载站、微信登录、天梯和正式运营承诺尚未提供。较早生成的离线包说明反映当时的发布状态，最新服务器状态以本页为准。

## 验证与边界

267 项自动测试通过，网页构建成功；双浏览器客户端实测行军、瞄准、炮管回弹和双方战后统计。海军模型、港口维修、潜艇遮挡及动态设施已做实机检查。

60／120／240 单位真实交战均非空且无 WebGL 错误，但 240 单位高画质仍较重，尚不承诺稳定 60 帧；压力采样出现较大调度间隔，原因需继续排查。公网高延迟与丢包、国产硬件兼容性仍需专项验收。当前为原创游戏化模型与分组关节动画，不是军事仿真或电影级模型。
