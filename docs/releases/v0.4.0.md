# v0.4.0 港口与后勤战争版

2026-10-06。感谢 CAI 与其他玩家持续试玩并指出海空、经济和补给问题。

## 新规则

- 全部军用舰艇及潜艇按 R 返回己方海军港口维修、补弹；维修速度每秒 30 生命、每点 0.35 资金。需要港口存活、供电、静止并脱离受袭三秒；资金不足会等待，整备完自动离开泊位。
- 常规地图新战局取消矿区与矿车：空运每 36 秒、后勤中心卸货 6 秒后到账 720；海图海运每 60 秒、港口卸货 9 秒后到账 900。两方镜像、卸货计费一次、同类设施不叠加收入。运输可被击毁，受袭或断电不能卸货。失去后勤中心时指挥部仅获每班 180 应急空运；失去港口不获得海运收入。
- 油井保留，子午环阵继续采矿。旧存档缺少经济模式字段时保留旧采矿规则；要体验新经济请重新开局。
- 远洋战区新增舰载制空机、舰载攻击机，实验室解锁，航母分配上限三架。适配飞机右键登舰，航母 U 起飞；起降需要停舰，维修／补弹还需要供电、资金和安全条件。普通空军单位不具备登舰资格。
- 实际舰载编组与旧内置舰载火力互斥，不能双倍攻击；航母沉没时停机飞机带损伤紧急起飞。
- 雷达与实验室解锁侦察卫星：费用 1000，冷却 120 秒，揭雾 8 秒，敌方收到预警；已探索区域保留，但实时迷雾恢复，不替代反隐或声呐。

## 画面与素材

新增后勤中心、补给运输机、集装箱船、052D 原创简化外形及细化航母的 GLB／Blender 源文件。新增空投补给箱、连续海岸泡沫；战机盘旋转弯、滚转，导弹有限转弯、俯仰和烟迹，火箭、炸弹、鱼雷采用不同展示高度。

052D 只参考公开外形，参数全为游戏平衡数值；两类舰载机使用通用外形，不冒充现役精确型号。

## 下载与兼容

修复“试听中文”在战局暂停时没有反应的问题，手动试听独立于暂停，正常战斗播报仍限频并遵守暂停。

下载 `Great-Powers-RTS-v0.4.0.zip`，完整解压后打开 `PLAY.html`；不需要 Node.js 或 Blender。升级前建议导出旧存档 JSON。包内继续提供 Linux 启动／菜单脚本与中文合成语音兜底，但国产系统实机认证和应用商店审核尚未完成。

公众号图文位于 `docs/wechat-fleet-20261006/`：七张桌面实机验收图与三张源模型渲染；图片类型逐图标明。

## 验证与边界

139 项规则测试通过。新增运输经济、港口与混合舰队、舰载机、卫星、弹道和存档兼容测试；1600 × 1000 与 1280 × 800 桌面功能验收覆盖实际服务、到账、起飞、卫星操作及非空画布。真实 PLAY.html 断网打开、保存／读档和模拟无中文系统音色时的 WAV 播放验证通过，无外部 HTTP 请求、WebGL 错误或横向溢出。

当前仍为单机试玩，联机、东风／核规则、更多月球科技及地图编辑器不在已完成列表。详见 [玩家建议验收清单](../玩家建议验收清单.md)。
