本版发行候选，2026-10-22。源码、下载与线上发布状态以本文件末尾实际记录为准。

## 本版内容

- 九大战区首版独立单机任务：深蓝、海峡、列岛、寒境、山口、归航、工业、战略警戒、月海。加上五项原有训练，共 14 项挑战。
- 工程师接管与付费修复、损毁设施保留遗址、争夺停产、工业产出配额、分批撤离去重、月海储能及中继网络。
- 列岛侧翼机场可接管修复，一次战机增援与后续整备；东南雷达提供视野，主线仍可独立完成。
- 国产坦克、驱逐舰与人员模型精修；人物远景三角面降低超过 80%，保留动作骨架。实例化绘制共享几何与材质，保留单体选择、炮塔及炮管动作。
- 引入授权清晰的坦克、F-22、吊机、地面材质，随源码与离线包附原许可。国产装备不使用游戏提取模型。
- 修复货船看不见碰撞距离内水面阻挡、护航舰占卸货点导致卡船、独立海图卸载队列不持续、第二批撤离不释放船位、月海缺少掩体数组等问题。

## 模式与限制

九战区是独立挑战，不是连续战役。六方仍是独立自由混战实验，每席 40 单位；新任务不在双人、六方或合作中开放。不包含铁路列车调度、全地图破坏、微信登录、排位或跨设备荣誉同步。

本版保留原八张双人地图、六域地图、战略威慑自选规则、旧战局和挑战成绩。战略警戒任务强制关闭核规则，与可选核威慑遭遇战分开。
