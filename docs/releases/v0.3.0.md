# v0.3.0：补给与海空运输升级

发布日期：2026-10-06。

## 本轮升级

- 飞机返航至空军基地后，消耗资金逐步维修和补弹；断电暂停、无资金不免费补给，近期受击不即时回血。满弹受伤飞机在机场停驻也可维修。
- 步兵、坦克、防空车、无人机、特色载具与部分舰艇新增有限弹药。步兵在兵营、车辆在工厂、空中单位在机场、舰艇在船坞补弹；射击批次是游戏化抽象。
- 维修补给车自动寻找可达的己方陆地作战单位，包括步兵；消耗库存和资金治疗、维修、补弹，缺货回厂，手动命令优先。可切换驻点保障，停止命令关闭自动寻找。
- 新增坦克登陆舰、远程轰炸机、重型运输机，以及对应原创 Blender 源模型与 GLB 运行模型。
- 登陆舰 12 格、运输机 8 格载重，步兵 1 格、车辆 4 格；装载单位不重复攻击/侦察。深海无法卸载，运输机只能安全陆地停驻装卸，不可嵌套装载其他运输工具。
- 轰炸机拥有 4 枚有限炸弹，固定落点范围打击，有飞行时间，可被战机、防空反制，不能空战或反潜。
- 无人机飞行改用空中移动，不再绕桥或受海面地面障碍限制；高低空与海陆单位仍独立分层。
- AI 按同一套经济、弹药和生产条件使用保障、新空军及跨岸运输，不赠送单位。
- 无中文系统音色、实时播报出错或超时时使用内置 37 条中文机械合成播报；不分发系统录音或语音引擎。附 Linux 启动及可选用户菜单脚本。

## 纳入公开发行的此前更新

手动存档、45 秒自动存档、JSON 导入导出、继续战局与返回主界面；部队/基地受袭语音、定位面板和小地图警示；材质、阴影、环境遮蔽与月壤纹理，精细/流畅画质切换。

更新试玩包、换浏览器、换电脑或移动 `PLAY.html` 前，请先在旧版导出存档。存档不上传服务器；读档后默认暂停。旧版没有有限弹药的单位在首次读档时获得初始满弹。

## 仍需反馈

目前仍是单机试玩版，不是军事仿真；新装备使用通用原创模型，不冒充某现役型号的精密复刻。有限弹药、费用、容量与医疗速度还需要真实对局长期平衡。

麒麟玩家反馈与本次“缺少中文音色”的浏览器模拟不等于所有国产架构通过验证。尚未在国产系统商店上架，具体适配与审核见 [计划](../国产系统适配与上架计划.md)。
