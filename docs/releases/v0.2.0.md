# 大国崛起 v0.2.0 国庆升级版

原创、非官方红警风格 RTS，桌面浏览器单机试玩。新版代码和源模型随仓库公开，保留 v0.1.0 供对比。

## 下载与运行

下载 `Great-Powers-RTS-v0.2.0.zip`，完整解压后，用现代桌面浏览器打开 `PLAY.html`。不需要安装 Node.js、Python 或 Blender。地图、模型、图片和原创配乐内置，游戏本体可离线运行；中文实时播报的音色及离线可用性取决于设备和浏览器。

SHA256 校验记录见 `SHA256SUMS.txt`。开发者源码可使用本仓库或 Release 页的 Source code；图文素材 ZIP 不是游戏安装包。

## 本次升级

- 新增 4480 × 2880 纵深战区，以及原创科幻地图「子午环阵」，共六张战场。
- 新增据点控制胜利规则、信标供电、光伏掩体与周期性通信扰动。
- 新增凌霄电磁炮车、云隼无人制空机、子午通信中继车，科幻地图独立科技条件。
- 20 个现实装备原型名称与资料定位，五种坦克、五种火箭炮的原创简化模型。
- 无人机重制、独立旋翼动画；机体、血条、目标圈与雷达区分蓝青我方和红色敌方，同阵营对战仍可区分。
- 建筑信息浮窗、生产设施出口、出厂动画与集结点；改进采矿车提前避障、矿区分流与路径重规划。
- 装甲朝向和科幻掩体规则，炮口闪光、后坐、曳光、碎屑、冲击波与导弹烟迹。
- 完整保留巡飞弹、电子干扰、激光反无人机、火箭炮、运输、补给，以及大型海图的驱逐舰、航母和潜艇。
- 同步装备来源、素材授权、联机方案、后续路线图和 12 图国庆升级文章。

## 验证与边界

94 项规则和展示逻辑自动测试通过，并检查生产构建、ZIP 完整性和最终离线 HTML 的桌面运行。自动测试不代表竞技平衡已完成，欢迎真实玩家反馈。

目前仍不支持多人联机。东风系列、核武器可选规则、052D 专属模型、扩展蜂群与完整月球基地是后续规划，不是本版已实现内容。现有模型是原创简化表达，不是现实装备工程复刻；国庆文章中的两张未来概念图不代表游戏实时画质。

本项目不是《红色警戒》官方续作，没有南天门 IP 官方联动。代码与作者可授予的素材权利按 MIT 提供，第三方和 AI 图片边界见随包授权文件；不分发 macOS 系统语音录音。

欢迎通过 Issues 提交地图、阵营、复现步骤与截图，也欢迎通过 Pull Request 共建。
