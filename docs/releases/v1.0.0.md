## 本轮改进

- 5760×5760六域会战，六席位自由对战，真人/AI混合部署，独立迷雾、淘汰、观战、同席重连与独立结算。单机一人五AI亦可玩。
- 六方每席40单位（含排队与生产），服务至多一场；协议3、Cookie和数据库与协议2双人服务隔离，不是3v3或正式天梯。
- 补齐房主交接、旧房主失权、重复序号拒绝、8人观战上限与断线释放、三胜利规则结算测试。
- 建筑内车辆脱困、上下层桥面直射限制、建筑说明鼠标移入不闪退，合入0.9系列成果。
- 中国制空机独立鸭翼双垂尾简化模型，高翼四发/T形尾翼运输机，近景人物迷彩和黑西装对比强化。
- 空空导弹小弧线追踪、空地俯冲，地面导弹保留高弧线；是游戏化可读性，不代表真实制导。
- 间谍驻留期间保持目标建筑情报，不暴露附近部队或敌方生产队列；拆弹后结束情报。
- 制空战机与舰载制空机可弱对地，攻击机与舰载攻击机可空战自卫；副任务基础伤害35%，自动优先主业，各任务共用弹药。轰炸机和月表无人制空机职责不改变。
- 修复多阵营潜艇探测表现的双人索引遗留；开发依赖source-map-js升级1.2.2，官方npm审计零漏洞。
- 统一1.0版本号、独立官网与完整下载地址，保留八阶荣誉、图鉴、存档和内置中文男女声。

## 下载须知

离线ZIP完整解压后打开PLAY.html，不安装Node；文件方式仅单机。局域网需要一台主机运行完整源码服务，其他玩家打开主机地址。Tauri安装包使用系统WebView，内嵌单机资源、独立HTTPS远程联网窗口，不授予远程页面本地原生权限。

macOS未Apple公证，Windows未代码签名；其他平台构建不等于实机验收。Linux需WebKitGTK4.1、GTK3与WebGL2，具体麒麟/UOS硬件仍待验证，不支持龙芯/申威承诺。升级前分别导出战局和荣誉JSON，别清理原数据。桌面各平台资产以Release实际文件清单和SHA256为准。
