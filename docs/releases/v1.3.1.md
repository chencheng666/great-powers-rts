# 1.3.1 山海防线先行版

独立五岛地图「山海列岛」与「列岛守望」串起登陆、占领、供电、海运和前线整备；同步提供「深蓝生命线 · 试航」。这是通往 2.0 的先行内容，不是完整九战区正式版。

## 本次修订

最终公网验收发现慢网首次打开挑战时，缩略图会在三维素材载入前生成，导致入口报错。现改为任务文字先显示、模型随后加载；加载失败保留任务信息并提示，进入作战可重试。关闭或切换面板后，旧请求不会覆盖新面板。

## 新内容与验收

- 列岛守望：4480×3200 无陆桥五岛地图，登陆舰分批卸载，三节点接管、失守夺回、能源供电、两批物资交付及驻守通关。有效抵港才结算，首批交付后可使用前线整备设施。
- 深蓝试航：有限补发、双港改派、下一班航道、暂停海运、有限恢复资金与独立维修泊位。
- 三维岸带、地表、能源阵列、沙滩标柱、港口、货箱材质与空船返航细节。
- 472 项自动测试通过；生产构建、离线实际运行、公网双人和六方、完整下载、桌面构建分别记录于 [发布验收](v1.3.1-verification.json)。
- 既有四关挑战、成绩、存档、复盘、图鉴、中文男女声及联机功能保留。原有玩家账号与战绩随服务端部署备份保留。

## 范围与共建

新群岛目前仅限单机；六方为独立自由对战实验，不是合作或3v3。侧翼岛争夺、机场、多岛扩张与其余战区仍待开发。社区三维模型目前仅整理授权候选，尚未导入新外部模型。

桌面包由 CI 构建，不代表各硬件已经实测。Mac 未公证、Windows 未签名；麒麟／UOS、弱网长局和 120／240 单位目标帧率仍需实测。国内直接镜像为免安装 ZIP，桌面平台文件从 GitHub 下载。

感谢 CAI 和持续试玩、提出建议的玩家。欢迎在 GitHub Issues 提交版本、系统、地图、复现步骤与截图，共同打磨到 2.0。
