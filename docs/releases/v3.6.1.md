# 网页3.6.1：选取与指挥修复

构建号：`20261111-selection-r1`。候选修复已完成；生产发布及线上操作结果待验收。

玩家反馈新版不能选取人物和战车，移动、战斗也无法操作。本次复现到两条输入被忽略的路径：单机在切换窗口后自动暂停，切回时仍保持暂停；显式拖图模式把未移动的左键轻点也当成拖图处理。

- 单机仅恢复由后台切换造成的自动暂停。手动暂停、菜单、图鉴、读档暂停及已经结束的对局不会被自动解除；联网暂停仍由服务器管理。
- 拖图模式的左键轻点保留点选；拖动继续平移镜头，右键轻点继续下达指令。中键、Alt拖图及Shift框选保留各自用途。
- 暂停按钮在暂停时明确标示“继续作战”。
- 保留3.6的地表、海面、模型和烟尘；不修改射程、碰撞半径、寻路或胜负规则。

新增后台恢复、手动暂停边界和拖图手势回归，以及合批模型的真实射线点选和屏幕框选测试；全量729项通过，生产构建通过。
