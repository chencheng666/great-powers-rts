# 2.0 模型、战区与发布推进

本轮用户授权开发、验收后推送 GitHub、更新下载包及国内服务器。未全部验收前不标为正式 2.0。

## 当前核对

- 代码基线为 1.3.1，main 分支；上一轮开放资产仍在工作区，需一并验收。
- 列岛守望已实现，旧深蓝开发记录中的“未开始”已过时。
- 深蓝仍复用跨海图；远东、海峡、山口、归航、工业、战略新任务及月面能源任务待补。
- 人物、车辆共享材质，但大量逐单位网格仍独立提交；240 单位此前帧间隔异常需要分离实际绘制负载与浏览器调度。

## 本轮顺序

1. 实例化军团绘制，验证迷雾、选取、动作、损伤、卸载与销毁；标准画质预算独立生效。
2. 精修自有国产坦克、舰船与人物；可复用资产逐项核验授权，不用来源不明的游戏提取模型。
3. 逐项补齐独立战区与任务，复用任务、占领、运输和存档机制；各战区分别记录真实完成状态。
4. 全量测试、实机任务与双客户端验证、性能采样、离线构建。
5. 仅将通过的内容统一发布，核验远端提交、完整下载校验、国内 HTTPS 与联机，保留回退。
