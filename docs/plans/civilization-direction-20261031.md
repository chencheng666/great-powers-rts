# 《大国崛起》国家发展与连续战役路线

2026-10-31 · 讨论规划；本文件中 3.0 后续能力不表示已经实现。

## 方向判断

可行，适合沿“现代海陆空即时战斗 + 国家经营 + 连续战役”发展。保留现有遭遇战入口与短局节奏，经营模式独立选择。先验证玩家是否愿意为了下一场战役继续经营，再决定是否扩大为完整的文明演进游戏。

参考依据：官方 [0 A.D. 功能介绍](https://play0ad.com/game-info/features/)把即时战斗、城市建设、文明差异与科技取舍放在同一游戏中，说明这种组合已有同类实践；该页部分内容明确标为计划，不能视为全部已经完成。[Freeciv 官方仓库](https://github.com/freeciv/freeciv)可供研究帝国发展策略游戏的规则组织，其代码为 GPL-2.0，本轮没有复制其中代码或素材。可借鉴设计问题与取舍，复用前逐项核对许可证和依赖。

本项目已有单位、生产、资源、据点、补给、AI、存档和联机基础；欠缺城市人口、研究队列、外交、领土归属及跨战局经济。不能把地图扩大或加几种武器就称为文明模式，也不能据此承诺商业成功。

## 版本顺序与退出条件

|阶段|主要交付|建议的可玩范围|验收门槛|
|---|---|---|---|
|3.0：完整战场|继续解决反馈清单、飞机与舰队、教学、手机操作、性能和存档；梳理各地图能力|遭遇战与现有挑战；核规则独立开关|完成首局、六机补给起飞、海陆空生产、旧存档、双人与六方断线回归；网页和安装包分别验收|
|3.1：国家发展原型|城市据点、产业建设、研究队列、有限的科技取舍|先做一张常规地图、单机、15～30分钟；资金与研究点两类主要投入，3条研究路线、每条3级起步|新手能理解建设→研究→作战→占领；三条路线都有可用策略，研究不会造成无解碾压|
|3.2：连续战役|区域归属、相邻地区进攻、补给线、跨关战役存档|3～5个相连地区；失败可以整备再战，单关可分段保存|退出重进不丢领土、研究与战局；补给中断与恢复可解释；旧遭遇战存档仍可读取|
|3.3：多种胜利|简化外交、贸易、AI倾向；军事、经济和科技目标|先单机验证，再评估独立的联机规则|AI能追求不同目标；玩家能提前看懂胜负条件；不存在无限交易或重复领奖漏洞|

这些是建议的实验范围，不是已承诺工期。3.1 试玩反馈不佳时，先改目标与节奏，暂停扩大世界地图。古代到太空、几十种资源、全球长期联网服和实时大世界暂不纳入首轮。

## 第一张“国家发展”原型

- 开局一个城市、一个生产区和可探索的邻近据点；城建有数量上限，避免无限堆建筑拖慢浏览器。
- 三条研究路线：工业（经济与维修）、陆空协同（侦察与战术选择）、海运（补给与海上控制）。优先开放能力和取舍，少用无条件伤害叠加。
- 每个据点提供明确效果及可切断的补给连接；地图同时给出安全扩张路线和风险更高的捷径。
- 军事目标保留基地战斗；经济目标为护送和物资交付；科技目标需建设并守住一个研究项目。第一次只启用其中两种，以验证平衡。
- 提供暂停、倍速的合理上限、情境指引和阶段存档；手机大按钮、可收起面板和拖拽地图继续共用。
- 跨战役成长先以城市外观、徽章和故事记录体现。公平联机不继承战力加成；现有荣誉不清零，不靠签到损失或体力墙逼迫回流。

## 工程落地

1. 单独的 CampaignState 保存领土、城市、研究与战役目标；每场战斗通过明确的配置输入和结算结果连接，避免直接修改所有现有战局。
2. 地图能力、科技条件和胜利条件共用规则函数，UI、服务器、存档验证与 AI 一致调用。不要继续用零散的 mapId 等号解锁通用武器。
3. 先单机原型。联机宏观层另做权威状态与校验，不接受客户端任意上报资源、研究完成或领土胜利。
4. 给战役存档独立版本号及迁移测试；普通旧存档不强制迁移为经营模式。领取奖励、结算和恢复须幂等。
5. 地图、模型按阶段加载；沿用 LOD、实例化、材质合批和动态关节预算。扩大航母/舰船前先测试航道、港口泊位、碰撞和低端手机帧耗，不能只改视觉比例。
6. 原有开源主线继续；本轮不改变开源许可。后续付费可优先评估原创战役内容、主题外观、支持者包，已有开源许可不会因后续闭源而收回。

## 用真实数据决定下一步

先记录现有基线，再对照新模式：启动成功率、开始到可操作时间、首局完成率、失败原因、第二局启动率、7日复玩、每场有效游玩时长、手机帧耗及错误率。按网页/ZIP/安装包分组，并遵守隐私选择和12个月原始统计保留规则。不以尚未取得的数据证明玩家喜欢某个模式。

每阶段只用可验证的试玩反馈判断是否扩张：玩家能否说清目标，是否愿意再开一局，是否能在退出后恢复。若长局流失高，优先缩短关卡和改善阶段结算。

## 第六批反馈的设计边界

常规直升机、常规弹道与反导扩展到常规海陆图；核威慑默认关闭，常规双人地图可开启且双方确认。月面、科幻、六方核规则和固定挑战仍按各自设计，不把实验单位强制塞进每张图。

本轮先统一固定翼机场/甲板展示比例、地面缩小和起飞平滑放大。整套舰船、运输机按玩家建议的15倍尺度重做，以及航母完整武器编制，需结合港口/航道/性能一起验收，列为后续模型与地图阶段。电子干扰与激光、野战防空与近程防空保留各自定位，通过卡片说明区别，暂不因名称相近直接删掉。
