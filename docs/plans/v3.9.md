# 3.9：前线增援与联合作战

本版在主战区“雪岭入海”的新单机对局启用前线增援规则。历史地图、科幻规则、联机和3.8旧存档沿用原规则；存档明确记录规则版本，不能靠地图名称推断旧档规则。

## 交付范围

- 四类保障建筑：指挥中心、后勤仓库、带雷达的六机位机场、六泊位港口；防御炮塔保留。电力合并至指挥与仓库；采购先决条件、维修补弹与技能来源同步迁移。
- 后方调入：飞机边界入场后落地，舰艇自外海驶入，舰载机直接前往航母；地面增援由可拦截运输航班投送。重车着陆交付，轻装备与人员伞降至本方仓库附近安全区域。
- 编制：订单预留，在途和出击占位；损失释放，基地毁坏转移到有空位的接收点，不能凭出击反复刷编制。取消与付费按现有队列退还已付资金。
- AI：按已侦察威胁调整兵种，保留维修与后勤预算；侦察、争夺、集结、推进、防守分阶段；运输护航与舰队掩护，避免长期覆盖返航和装载命令。
- 表现：机场雷达、港口泊位、增援投送和落地状态可读；沿用程序生成。
- 性能：目标搜索空间索引、每步实体索引、限制非必要寻路重算，验证长局对象回收与帧耗时。

## 后续

燃油与加油机/补给舰属于下一阶段，不在本版半成品接入；核规则仍保留历史战区的可选模式。4.0研发分支和连续战役不提前标为完成。

覆盖订单取消与满位、在途存档、损失/基地摧毁、运输载重与拦截、五AI正常资源预算、迷雾一致、海陆空协同、长局内存与路径开销。构建、离线包、真实浏览器操作及正式来源分别记录。上线前检查房间，备份与保留数据库、历史下载和独立站点，完成Git和公网资源回读。
