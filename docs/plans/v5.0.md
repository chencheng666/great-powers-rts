# 5.0 长期玩法征集与验证路线

2026年11月3日。当前发布版仍为2.0.2；5.0是长期方向，以下内容均为候选设计，不是已完成功能或上线日期承诺。接续[3.0迭代方向](v3.0.md)与[国家发展原型](civilization-direction-20261031.md)，先完成旧阶段验收，再决定是否扩大。

## 玩家希望留下来的理由

保留随开随玩的即时遭遇战，另行尝试可分段保存的经营与连续战役。围绕建设、侦察、补给和战术取舍创造不同解法，避免只加地图尺寸、兵种数量或重复刷取时间。

|阶段|小范围验证内容|进入下一步的依据|
|---|---|---|
|3.0 战场打磨|加载、拖图、教学、移动与巡逻、海陆空、旧档与联机恢复|首局可完成；玩家能找到模式、理解目标与补给；各发行渠道分开验收|
|经营与连续战役原型|沿原3.1～3.3方案，先做一张图、有限科技，再做3～5相邻区域|建设与战斗之间有可解释的取舍；退出可恢复；失败后仍有继续尝试的路径|
|4.0 候选整合|若原型受欢迎，再整合区域规划与即时战场切换、阶段结算和AI目标|战役进度一致、资源不重复结算；能完成一轮小规模战役，旧遭遇战独立保留|
|5.0 长期目标|在已验证基础上扩充不同地图目标、经济与科技路线、合作玩法和可重玩挑战|玩家愿意再开一局；不同路线均可用；不是必须长时间在线才能继续|

## 优先讨论的取舍

- 更喜欢15～30分钟的一局，还是可以分几天继续的战役？两者分别保留入口。
- 除摧毁基地外，是否期待护航、守点、撤离、经济建设、科研或合作目标？一次只挑少数目标验证AI与平衡。
- 科技优先提供新能力与代价，而非所有旧单位瞬间无条件升级；旧装备改装需要设施与费用，是待验证方案。
- 账号与跨设备同步、匹配、模组接口分别评估安全、隐私、维护成本；不作为本轮已交付功能。
- 外观与纪念奖励保持不增加公平联机战力；保留已有存档、荣誉和离线玩法，不用每日强制签到或长时间生产墙拉长时长。

## 征集格式

玩过的类似游戏／最喜欢的机制／当前最影响体验的问题／最想优先的一项改进／愿意再开一局的原因。故障附设备、浏览器或安装包版本、地图和复现步骤，截图可选。参考其他作品的设计问题，不复制其代码、音效与美术资源；复用开源资产须核对许可和来源。

## 衡量与工程边界

先验证单机最小原型，再考虑联网宏观层。战役数据单独版本化，结算幂等，联网资源和进度由服务端校验。按需加载、LOD和单位上限随地图一起验收。已有启动、错误与时长统计仅在既有披露和用户选择范围内使用；新的复玩指标需先检查统计定义、隐私与样本有效性，当前没有数据证明某个方案已受欢迎。
