# 三维写实重制与《几猫》深度核对

## 目标和依据

这次覆盖建模、地形、水面、战斗和声音的整体表现，不把只换几架飞机或调一次颜色称为完成。以同一张山海会战地图、同机镜头和军团压力场景比对，并在官网与上海两个服务实际回读。独立科幻版、商店安装包、玩家数据库属于保留边界。

用户附件《几猫国产3A大作_V1(2).html》共1,425,707字节，SHA256 `9e55b5200b088adaf8e1152da04efc0d3b25e236e6baf2dee96f81e23e084966`；应用约从字符733853开始。没有将打包引擎内置能力都算作作者启用的效果，也不公开分发附件。

## 覆盖清单

- 陆地模型：保留各阵营现有轮廓和炮塔关节；统一室外环境光；表面脏污、消光及损伤；增加贴坡悬挂。
- 人物：保留各兵种人物、服装和装备差异、易读比例与角色标记；近远模型互斥；不得被改地表后淹没或变成不易选中的真实小点。
- 空中：复查七款新曲面与四款停机外形、座舱反光、地面/空中比例、转弯和尾焰；不把退役外形重新载入。
- 舰艇：波面同源起伏，原斜角甲板、24机位与动态调度继续生效；舰艇尾流跟朝向，潜艇保留潜浮表现；海面反射不绘制阵营/选择辅助线。
- 建筑：工厂/兵营/设施保持三维模型、入口和维修/生产动作；新室外照明与表面污染不改变建设占地。
- 地图：山海会战山脊由连续破碎岩层重做；普通谷地/海岸山丘增加同源侵蚀；摄影草岩、砂土、寒境高处积雪、工业道路各有材质；月表保留独立陨坑与月壤，不套草地。
- 自然物：连续风化岩体、三平面岩壁、立体树干与交错叶簇。桌面默认近景可显示立体树，团战或降分辨率后切轻量树冠；移动端默认轻量。
- 战斗：发射闪光、炮口尘、连续尾烟、火焰/碎片/冲击、贴坡焦痕、持续黑烟与维修后熄烟；不修改射程、伤害或命中。
- 声音：短卷积早反射；已有武器/飞行/航行声、左右定位、音乐和无线电分总线继续有效。
- 运行与发行：新增媒体仅0.53MB；纹理复用、固定粒子预算、标记实例绘制、异步预编译；最终完整测试、实机、Git/官网/双服务与数据库保留分别记录。

## 资产

摄影材质来自Poly Haven：Leafy Grass（Charlotte Baglioni）、Rock Face（Greg Zaal / Dario Barresi），均为CC0。本站派生文件共534,646字节，缩至256像素，打包法线RG/粗糙度B/遮蔽A，草地调色、岩壁灰岩亮度归一。`assets/third-party/polyhaven-terrain-20261111/来源与修改.json`记录原始链接和摘要。运行时不访问第三方CDN或API。源码不是从Poly Haven API项目复制，API代码的AGPL许可与所下载CC0资产应区分。

## 不冒称的内容

不是3A成品、真实武器仿真或流体求解器。没有照搬FPS四足IK、SSR、全场无限体积光，也没有将PCF说成PCSS；这些不适合当前RTS预算的技术没有为凑清单强行接入。完整目标按上述可玩战场验收，尚无证据的结果不写通过。
