# 3.0 指挥官征途

本轮以现有海陆空即时战略为基础，把首局引导、后续目标与复盘接起来。国家经营和多人共管国家继续作为后续原型方向，详见国家发展路线和5.0征集路线。

## 本轮功能

- 灰谷入门从四步扩为六步，补充维修补给和据点接管。只按教学开始后的真实行为推进，伤车尚未出现时可以继续正常作战。
- 作战路线将九项现有挑战整理为陆地指挥、深蓝航线、协同任务。原挑战成绩直接接续进度，胜利后推荐下一任务，全路线完成后可提升星级。
- 复盘根据运输损失、整备、战损、生产与据点控制给出最多三条建议。独立任务失败补充目标操作提示，旧存档继续标明统计起点。
- 新图标取意于篆字的围合结构，红色笔画内收，金色外框连续；官网、游戏、桌面源图统一。
- 首页点击播放《国际歌》交响器乐编配，战斗可选两首原创交响风配乐。保持静音、音量、暂停与前后台控制。
- 修复网站版本显示；增加本站两域名间的本机荣誉恢复；在读取失败时明确显示异常，避免默认称号看起来像清零。只恢复完整包含当前记录的较新档案，分叉记录保留原状。
- 阵营选择展开显示已有加成、特色装备和战术规则，帮助玩家理解各自取舍。
- 按真实错误分类给出图形恢复指引，WebGL被禁用时引导启用图形加速，连接中断时保留战局和导出入口。
- 官网与开发手记加入玩家交流群，群码按2026年11月13日到期处理。

## 发布验收

1. 自动测试、正式构建、旧存档与荣誉读写及挑战档案回归。
2. 浏览器实际首局、配乐切换、菜单返回、六步教学、挑战通关与下一任务、存档恢复和窄屏检查。
3. 网页与ZIP通过，桌面构建按CI结果与实际硬件验收范围标明。
4. 发布前检查双人、六方是否有对局，备份玩家数据库，原子切换并回读公网资源。
5. 官网开发手记公开，公众号文章保存在草稿箱；素材使用本轮截图，群码保留原图。

## 后续原型

玩家提出的长时间国家经营、多玩家分管集团军、科技升级与阵营专属模型纳入后续验证。先用小规模战役检验持续经营和协同分工，再决定完整规则与数据结构。
