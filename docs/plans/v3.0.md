# 3.0 迭代方向

当前稳定发行版仍为 2.0.2；以下为开发路线，不表示已实现或已上架。

## 第一阶段：更清晰地开始游戏

- 本轮：主界面按游戏介绍、指挥官中心、作战部署分组；统一入口与表单对齐，窄屏纵向布局。
- 已实现第一阶段：战场卡片、地图类型筛选、搜索、地图定义生成的地形示意、玩法与难度提示；独立任务仍从战术挑战进入。
- 验收：新玩家能找到模式、切换地图并开始一局；存档、荣誉、成长与联网入口都可用；390px 无横向溢出。

## 第二阶段：让第一局更容易理解

- 已实现灰谷入门的选择、移动、扩建供电、生产四步实操教学，可关闭或收起；维修补给与胜利目标提供提示。读档后按当前战局重新开始教学，教学进度不计奖励。
- 接续：维修补给与地图目标的情境教学及失败复盘。
- 教学可跳过、可重看；失败后给出具体原因与建议，保留玩家已有进度。
- 优先根据匿名错误记录和玩家反馈修复阻碍开局、存档、移动与战斗的问题。

## 第三阶段：更多值得重玩的目标

- 地图与挑战按海陆空特色整理；新增目标前先完善现有玩法。
- 成长目标、外观与纪念奖励继续保持不影响联网战力。
- 验证难度曲线和单局节奏，再扩展地图与任务；不以强制签到或战力付费作为留存手段。

## 3.0 发布条件

- 核心玩法、存档迁移、联网断线恢复与错误上报回归通过。
- 实际验证桌面与窄屏页面、首局完整流程、存档恢复及关键玩法。
- 记录首屏加载和帧率基线，在相同环境对比优化效果。
- 官网、网页、ZIP、桌面安装包明确版本和兼容范围；统信单独走版本审核。
- Git、官网和服务器同步，保留玩家数据；未实测平台明确标记，未完成事项不写成正式功能。

## 国家经营方向（2026-10-31）

保留即时遭遇战，另行验证国家经营与连续战役。具体阶段、原型范围、工程边界及验收标准见 [国家发展路线](civilization-direction-20261031.md)。3.0 优先稳定与完整战场，3.1 再做有限科技与城市原型；后续能力均为规划。
