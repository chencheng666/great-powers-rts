# 4.0 发展路线：让指挥有选择，让战役值得重玩

## 方向

在现有海陆空 RTS 上增加战术深度和持续目标。先改善默认镜头下的辨认、选取和阵营理解，再用小规模连续战役验证长期经营。暂不直接铺开跨时代文明、外交、多人共管国家，避免机制数量超过玩家理解和性能预算。TapTap 科幻版独立维护，官网现代题材改动不会自动混入送审包。

## 第一阶段：3.1 易读战场（本轮实现）

- 默认易读比例：100% 镜头人员显示为原尺度 1.5 倍、地面车辆 1.2 倍；拉远到 45% 时分别封顶 1.9 倍和 1.4 倍，拉近不继续增大。飞机、舰船、建筑、月表原尺度保留。
- “界面设置 → 单位比例”支持原比例与易读比例，偏好存本机。人物的兵／工／侦标识有暗底，随迷雾、登载和死亡消失。
- 小横血条：人员28×5、车辆34×5屏幕像素；关注单位保留数字和弹药，大队选中收起细节；桌面最多120条、窄屏64条，优先关注与危急单位，限制避让距离。
- 鼠标选取补偿半径 18 CSS 像素、触屏 26 CSS 像素；保留模型直接命中优先、最近己方对象选择，空白地仍可框选。
- 碰撞、射程、移动、弹药、伤害和人口不随显示尺寸变化；原存档和联机协议不变。
- 五阵营已有特色装备采用五种原创低模轮廓，保留炮塔、炮管和火口。东亚“蜂群母机”更名“蜂群指挥车”，明确地面路径，避免误以为可飞行跨海。
- 阵营说明给出职责、建议编队、打法和弱点；图鉴、生产卡和战场模型使用同一模型入口。

## 第二阶段：战术选择

每阵营先做两条互斥的局内研发分支，而不是所有科技叠满。候选方向：华夏阵地防护／机动防空，北境阵地攻坚／快速突破，西陆重装维持／空地协同，东亚侦察蜂群／精确反甲，新月情报控制／机动压制。

每项研发必须有成本、准备时间、可见效果、反制和取舍；普通兵种始终有价值。数值以同预算阵容对战、不同地图胜负和人工试玩验证，不用现实装备宣传参数代替平衡。此阶段尚未实现，具体加成在对战原型后定稿。

## 第三阶段：短战役和持续经营

先做 3–5 个区域的战役：选择下一目标 → 部署有限编队 → 完成即时战斗 → 支付维修与补充成本 → 带着结果进入下一关。战后保留基地或区域进度，允许中途保存。失败提供撤退／重组机会，不让玩家一次失误损失数小时进度。

区域目标分别验证护航、接管、守备、撤离和资源运输；后勤与侦察改变下一关条件。保持单场约 15–25 分钟的设计目标，战役可分段完成。时间是设计目标，须以实测校准。

## 第四阶段：反复游玩的理由

每日／每周同种子挑战、战役难度与随机事件、战后关键决策复盘、无战力付费的纪念外观。先做单机可信结算，再讨论排行榜；联网成绩必须服务器校验。尊重退出和休息，不靠强制签到保留进度。

## 4.0 正式版验收门槛

1. 新玩家在默认镜头下能辨认工程、战斗和支援单位，完成选取、框选、移动、维修和接管，不依赖反复缩放。
2. 五阵营有清楚的优势、弱点和至少一种有效反制；每条科技分支有可复现成本和收益。
3. 一条完整多关战役能够开始、失败恢复、保存续玩和通关；旧存档不丢失。
4. 120 单位混战与长时间海陆空对局验证后再确定性能承诺；本轮受控测试不能代替此门槛。
5. 官网、网页、桌面、离线包、商店分别标明版本与验收状态，不把先行版本叫作完整 4.0。
