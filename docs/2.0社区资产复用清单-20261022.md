# 2.0 社区三维资产复用

日期：2026-10-22。用户要求：优先复用现成的爱好者开源模型，不再默认所有模型都由简单几何体重建。

## 接入顺序

优先解决坦克、飞机、步兵、发电设施和港口的辨识度与材质。群岛地图与任务继续使用现有可运行资产，不因候选模型筛选中断规则开发。

流程：原作者页面核验 → 保存作者、原始链接与具体许可 → 检查是否原版游戏提取 → 对照现有模型视觉 → Blender 减面及 UV／贴图整理 → 拆分炮塔、炮管、履带或机翼动作 → GLB 本地加载 → 图鉴与实战验收 → 署名及许可随离线包分发。

不能只根据 GitHub 仓库的代码许可证推断模型可用。禁止把第三方资产自动改标 MIT；CC BY 模型保留署名、许可链接和改动说明，CC BY-SA 等另核衍生义务。页面允许下载并不代替再分发许可。

## 视觉与性能门槛

- 模型必须比当前对应资产有可见改善；保留自然比例、材质层次与阵营识别，不能只提升面数。
- 模型轴向、地面接触点、尺寸和炮口位置统一；独立炮塔、后坐、履带及机翼动画不能丢失。
- 优先复用原始 PBR 贴图，按场景压缩分辨率；不使用在线热链，单机离线也能完整加载。
- 同材质合批与共享纹理，远景使用低细节版本；近景细节有数量上限，先在图鉴和小战斗验收，再测试 120／240 单位。
- 每项登记实际文件、校验值、原作者、许可、改动、三角面、材质／纹理预算及测试截图；未完成登记的候选不能进入正式包。

本次只是候选与流程记录，没有把外部网格混入当前游戏。后续实际接入后更新 `ASSETS.md` 与随包署名，不宣称当前全部模型已更换。
