# 2.0 社区三维资产复用

日期：2026-10-22。用户要求：优先复用现成的爱好者开源模型，不再默认所有模型都由简单几何体重建。

## 复用范围与优先级

复用范围覆盖装备、人物、建筑、地图环境和资源采集设施。下表为整体筛选计划；本轮已落地范围另列于文末，不表示所有类别均已更换。

| 优先级 | 类别 | 优先寻找的素材 | 接入时保留的玩法要求 |
| --- | --- | --- | --- |
| 第一批 | 重点装备 | 主战坦克、战机、直升机、登陆舰、驱逐舰 | 炮塔与炮管动作、起降与运输位置、阵营色、轮廓辨识；只换美术不能暗改射程与伤害 |
| 第一批 | 地面与材质 | 土壤、岩石、混凝土、沥青、金属、橡胶与玻璃材质 | 减少地面发白，统一纹理尺度、粗糙度与光照；地表细节不能遮盖单位和弹道 |
| 第二批 | 基地建筑 | 兵营、工厂、电站、港口、雷达、仓储与维修设施 | 出兵点、占地、入口、接地底座、受损状态与供电状态清楚 |
| 第二批 | 资源与补给 | 油井、储油罐、集装箱、运输船、补给站、矿石与采集设备 | 玩家能分辨可占领、可采集和纯装饰物；与现有地图资源规则匹配，不因素材存在就增加一种资源 |
| 第三批 | 环境与人物 | 植被、礁石、堤岸、道路、桥梁、码头模块、步兵与机器人 | 环境实例化和碰撞简化；人物有骨骼及动作使用许可，姿态、武器握持与阵营辨识一致 |

地面贴图、环境模型与模块化建筑优先从许可清楚的素材库选取；地图布局、航道、登陆点、资源分布、占领点和供电网络仍由本项目设计与测试。漂亮的整张场景不能直接替代公平、可寻路的 RTS 地图。

## 来源筛选规则

- Sketchfab、OpenGameArt：优先找原作者发布的 CC0／CC BY 单项资产，逐项核对原始页面、源包及贴图来源。网站搜索筛选只用于找候选，不作为授权结论。
- Poly Haven：官方模型、贴图与 HDRI 使用 CC0，允许修改与再分发；优先用于地表、岩石、植被、工业道具及光照参考。资产许可不等于网站截图、标志和示例渲染也同样开放。依据：https://polyhaven.com/license 。
- ambientCG：官方资产使用 CC0 1.0，许可明确允许游戏包含原始文件；优先筛选地表、道路、混凝土、金属等 PBR 材质。依据：https://docs.ambientcg.com/license/ 。
- BlenderKit：官方列出的许可是 Royalty Free 和 CC0，并非“免费模型大多 CC BY”。本项目优先选 CC0；Royalty Free 的游戏使用条款要求资产不能轻易提取，而本项目公开 GLB、GitHub 源码与离线包，因此在未取得额外许可前不纳入公开素材。这是针对本项目分发方式的筛选决定。依据：https://www.blendkit.com/docs/licenses/ 与 https://www.blendkit.com/docs/licenses/licensing-faq/ 。
- PPM、红警 DIY 等社区：可以寻找作者原创、明确允许本项目修改与公开分发的作品；不能把“允许 MOD 使用”推断为允许独立游戏、商标或原版素材再分发。
- Open3DModel、3D Warehouse、MakerWorld、GrabCAD、Thingiverse、Sloyd 等作为补充线索；本轮没有核准这些站点的具体资产，不能对整个站点统一承诺商用或再分发。打印网格、工程装配和未知转载不直接入库。

CC BY 资产保留作者、许可链接与修改说明，不改标为 MIT。NC 是否适用取决于具体使用目的和情境，不能简单说“公开免费 Demo 就一定是商用”；为兼容项目开源再分发及未来发展，本项目仍优先不选 NC，必要时向权利人另行取得许可。依据：https://creativecommons.org/licenses/by/4.0/ 与 https://creativecommons.org/faq/#does-my-use-violate-the-noncommercial-clause-of-the-licenses 。

不把截图、AI 重生成或减面作为绕开来源授权的办法。优先直接在 Blender 中整理有合法来源的原模型，保留原 UV、PBR 和结构；只有确有需要且输入、输出权利均确认后才考虑 AI 辅助处理。

## 接入顺序

优先解决坦克、飞机、步兵、发电设施和港口的辨识度与材质。群岛地图与任务继续使用现有可运行资产，不因候选模型筛选中断规则开发。

流程：原作者页面核验 → 保存作者、原始链接与具体许可 → 检查是否原版游戏提取 → 对照现有模型视觉 → Blender 减面及 UV／贴图整理 → 拆分炮塔、炮管、履带或机翼动作 → GLB 本地加载 → 图鉴与实战验收 → 署名及许可随离线包分发。

不能只根据 GitHub 仓库的代码许可证推断模型可用。禁止把第三方资产自动改标 MIT；CC BY 模型保留署名、许可链接和改动说明，CC BY-SA 等另核衍生义务。页面允许下载并不代替再分发许可。

## 视觉与性能门槛

- 模型必须比当前对应资产有可见改善；保留自然比例、材质层次与阵营识别，不能只提升面数。
- 模型轴向、地面接触点、尺寸和炮口位置统一；独立炮塔、后坐、履带及机翼动画不能丢失。
- 优先复用原始 PBR 贴图，按场景压缩分辨率；不使用在线热链，单机离线也能完整加载。
- 同材质合批与共享纹理，远景使用低细节版本；近景细节有数量上限，先在图鉴和小战斗验收，再测试 120／240 单位。
- 每项登记实际文件、校验值、原作者、许可、改动、三角面、材质／纹理预算及测试截图；未完成登记的候选不能进入正式包。
- 不同来源统一到现代写实的视觉目标，统一比例、色彩与做旧程度；不因 CC0 就引入明显卡通、体素或与现有画面不协调的资产。
- 资源设施与装饰物分开标记交互、碰撞、占领范围和出入口；近景细节不能造成运输补给卡路或改变登陆通道。

## 第一批实际接入

2026-10-22 已完成本地运行时替换：Sketlux / yd 的 CC0 Abrams、西陆 F-22（andertan，CC BY 4.0）、Poly Haven CC0 工业吊机、草岩地表及磨损混凝土。F-22 使用的是另一条许可明确的原作者来源，不是上表排除的 Hulio / bohmerang 来源链。

- `assets/third-party/manifest.json` 保存原作者链接、许可、实际文件 SHA-256 与几何预算。
- `scripts/build-open-assets.py` 整理坐标、炮塔／炮管、近远景并减面；源文件禁用脚本执行。
- `src/open-assets.js` 实际加载本地 GLB 与 PBR 贴图，缺少某项资源时保留对应原模型；不会在运行时请求国外素材站。
- 仅替换西陆普通坦克和战机，不将一个型号套用到所有阵营。港口保留原有码头布局，替换两组吊机及混凝土表面；月表仍保留原月壤。
- 模型、贴图与原创代码的许可分开。`THIRD-PARTY-ASSETS.txt` 随离线包分发，游戏操作说明内也提供署名文件。
- 本轮不修改射程、伤害、载重、碰撞、生产或资源规则；本地验收通过不等于线上已发布。
