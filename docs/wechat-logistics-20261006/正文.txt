粉丝玩了两小时，我的开源“红警”又升级了：登陆舰、轰炸机、自动补给来了

先认真感谢一位粉丝：CAI。上一期文章发出后，他连续玩了约两小时，不只鼓励我，还把飞机不回血、部队无限弹药、补给车需要自动保障、无人机不能跨海、国产系统缺中文语音等问题逐条写了下来。本文前面这些升级建议，以及后面关于《真实战争》、卫星侦察、导弹轨迹和应用商店的想法，都来自他的反馈。

他有句话让我很受鼓舞：“游戏的趣味性，武器的制衡性是有了。”对一个仍在迭代的开源项目来说，愿意认真玩、认真指出问题，就是很珍贵的支持。谢谢 CAI，也欢迎每位玩家继续提建议。

这次继续和 GPT 6.1 / Codex 一起开发。我希望它不只是一个“AI 能做游戏”的演示，而是军迷朋友愿意反复打开、能讨论装备与战术、也能一起维护的作品。新版 v0.3.0 已整理成离线试玩包，重点是电脑端体验。

先说旧版：已经能打一场完整的陆海空对局

《大国崛起》是受经典即时战略启发的原创非官方浏览器游戏，不是官方《红色警戒》续作。此前已有五阵营、六张地图、采矿建造、电脑对战、战争迷雾、电子战、海军与科幻月表战区；建筑有信息浮窗，部队从生产设施出口出现，大地图可拖拽，全屏和收起侧栏也已支持。

这次同时把保存进度、45 秒自动存档、JSON 导入导出、继续战局、返回主界面，以及部队受袭语音和定位警报纳入公开版本。玩到一半可以停，收到警报可以点过去看，不必再靠记忆找战场。

【配图 images/09-save-and-menu.png】
真实桌面截图｜保存后返回主界面，继续战局不再从零开始。

第一件事：飞机回基地，真的会回血了

CAI 指出：飞机飞回基地补给，血条却没有恢复。这版已经补上。飞机在有电的空军基地停驻后，会逐步维修、补弹，再继续原来的任务；满弹但受伤的飞机也能主动返场。选中空军后点击补给图标，或按 R 即可。

【配图 images/03-airfield-repair.png】
真实游戏验证场景｜飞机停驻机场维修，血条、弹药和补给状态来自当前战局。

维修不是免费回血：需要资金，基地断电就暂停，刚被攻击时不能立即靠机场把伤害抵消。这给防空压制、机场保护和轮换出击留出了空间。

第二件事：从无限弹药，走向有补给的推进

步兵、坦克、防空车、无人机和部分舰艇现在都有有限弹药。兵营、工厂、机场、船坞分别承担相应补给，消耗资金和时间。步枪按“射击批次”计数，不逐发模拟真实弹匣；激光反无人机车依然使用过热与冷却机制。

【配图 images/01-auto-support-before.png】
真实游戏验证场景｜补给前，步兵和坦克处于受损、缺弹状态。

维修补给车也不再只等着你把伤兵送过去。出厂后默认自动寻找可达的友军陆地作战单位，包含步兵，开过去医疗、维修、补弹。库存不足会回工厂补充；手动移动命令优先，停止命令会关闭自动寻找，也可以切换到驻点保障。

【配图 images/02-auto-support-after.png】
真实游戏验证场景｜自动保障后，步兵和坦克恢复，补给车库存与我方资金同步消耗。

它不能修海军和飞机，不能跨海追逐陆军，也不会照顾敌方单位或车内乘员。我的目标是让后勤成为战术选择：远程火力需要保护，持续推进需要保障，昂贵单位也不是冲过去就能永远开火。

第三件事：登陆舰、运输机、轰炸机登场

坦克登陆舰：装甲终于有了跨海路线

【配图 images/11-landing-model.png】
Blender 源模型展示｜车辆甲板、舰桥、栏杆、艏部跳板与识别带。不是游戏截图，也不是某现役型号的精密复刻。

登陆舰有 12 格载重，步兵占 1 格，车辆占 4 格。可以运三辆坦克，也可以混载。选中陆地部队右键友方运输单位即可装载，靠岸后点击卸载或按 U。它没有武装，需要护航；深海不能卸载，船被击毁时乘员也不是无敌逃生。

【配图 images/04-landing-loaded.png】
真实游戏验证场景｜登陆舰装载坦克和步兵，界面显示实际占用载重。

【配图 images/05-landing-unloaded.png】
真实游戏验证场景｜靠岸卸载，乘员回到可行走的陆地，没有复制出新单位。

重型运输机：把运输成本和落点安全算进去

【配图 images/13-airlift-model.png】
Blender 源模型展示｜四发布局、后舱跳板和起落架，是这版实际使用的原创通用运输机。

运输机有 8 格载重，支持步兵与车辆混载。装卸需要在安全陆地停驻，不允许在海上空投坦克，也不能把另一艘运输船或另一架运输机塞进去。这不是精细空运仿真，而是可读、可反制的游戏规则。

【配图 images/06-airlift-cargo.png】
真实游戏验证场景｜运输机的乘员与载重状态；装载后的单位不独立开火或提供视野。

远程轰炸机：范围打击，但不是万能答案

【配图 images/12-bomber-model.png】
Blender 源模型展示｜后掠翼、发动机短舱与腹部弹舱；模型和脚本一并开源。

轰炸机需要实验室，携带 4 枚炸弹，对固定落点进行范围打击，炸弹有飞行时间。它不能空战或反潜，需要制空与防空压制配合；弹药用完要返场。战机和防空可以反制轰炸机，炸弹本身目前没有拦截机制。

【配图 images/08-bomber-strike.png】
真实游戏验证场景｜轰炸机对地投弹，敌我血条和机体识别保持不同颜色。

第四件事：无人机能直接飞过海面了

大型海图上的无人机此前错误地受到了地面寻路限制，看起来像“必须走桥”。现在改用空中移动，直接跨海，不再绕桥。空中、地面和水面单位仍按层分离，解决跨海问题的同时保留避让和射界规则。

【配图 images/07-drone-over-sea.png】
真实游戏验证场景｜无人机跨越远洋战区海面，不借用桥梁路径。

画面也继续打磨了月壤、地表凹凸、阴影、环境遮蔽和受袭提示。新模型仍是适合俯视战场的简化模型，不会把这一版说成 3A 写实画质，精度、动画和海岸效果都还会继续提升。本文功能截图使用真实运行版本，为展示规则安排了验证场景；不是自然对局统计，也不是 AI 生成的伪游戏画面。

第五件事：没有系统中文音色，也能听到中文了

CAI 反馈银河麒麟可以玩，但听不到中文语音。少了“部队待命”和“我方部队遭到攻击”，确实少了很多即时战略的味道。因此这版内置 37 条离线中文播报：有系统中文音色就优先使用系统语音，没有或播报失败时回退到 WAV，不要求玩家安装语音引擎。当前兜底是机械合成音，后续希望补上授权清晰、更自然的配音。

【配图 images/10-chinese-voice.png】
真实桌面截图｜顶部扬声器打开设置，取消静音、调高中文语音，恢复游戏后点击“试听中文”。

简单操作：解压新版，打开 PLAY.html，点击“开始作战”；检查系统音量和标签页静音；在声音设置里把总音量、中文语音都调到大于 0，点击试听。语音有队列和冷却，暂停时请先恢复。详细排查教程也随试玩包提供。

中文语音使用教程（含无声排查）：https://github.com/chencheng666/great-powers-rts/blob/main/docs/中文语音使用教程.md

国产系统这条路，值得认真做

CAI 还提到 XCPDF 的社区共建与统信上架经历，建议我们试着走同一条路。这给了我启发：无需给玩家配置开发依赖、解压就能打开的网页即时战略，也许能成为国产桌面娱乐的一种选择。喜欢国产装备、关心国产系统，与参与开源创作，并不矛盾。

这个国庆，从对国产装备的兴趣出发，我更希望把热情落到一个能玩、能修改、能持续变好的作品里。爱国情怀可以是创作的起点，但不能替代游戏质量：阵营优势要有代价，装备要有反制，双方应遵守同一套规则，输了也能看懂原因。

当前增加了 Linux 启动脚本和可选的用户菜单安装脚本，无需管理员权限；但仍依赖电脑已有的现代浏览器，不是原生 DEB/RPM。银河麒麟能玩的情况来自 CAI 实测，我这边验证了无中文系统音色时的浏览器离线播报，还没有完成各国产系统和硬件的实机认证，也尚未申请或通过商店审核。

国产系统适配与上架准备清单：https://github.com/chencheng666/great-powers-rts/blob/main/docs/国产系统适配与上架计划.md

《真实战争》给的启发，留给下一轮

CAI 提到 2001 年的《真实战争》，特别喜欢舰载机起飞、空战轨迹、导弹飞行和卫星侦察。我会参考这些体验方向，不复制原作素材。下面是后续计划，不是这版已经做好的功能。

航母：现有航母已能出动有限数量的自带舰载机，下一步研究搭载玩家自行生产的适配飞机，以及甲板起降动画。空战：改善转弯、俯仰、追击和导弹尾迹。弹道：火箭炮已有弧线展示，导引导弹还需要与子弹曳光进一步区分，不把所有导弹都画成同一种抛物线。

卫星侦察：研究短时揭雾、资源费用、冷却和预警，不直接给玩家永久全图透视。装备：继续评估东风系列、052D 独立模型、协同无人系统、超音速单位；核武器只考虑双方事先知情的可选游戏规则。科幻：在子午环阵基础上扩展月球基地、能源和通信玩法，不把想象设定冒充现实军事项目。

联机也在规划中：先做双人局域网，用权威服务端校验命令、统一结算资源和战斗，客户端只提交操作并接收各自可见的状态，避免把敌方迷雾信息发给对方；再考虑公网房间、断线恢复和观战。当前仍是单机版，没有可用的联机入口。

技术只说一点：规则、画面和素材分开

输入与界面 → Game 战局规则与双方状态
             ├─ 补给 / 运输 / 投射物 / AI
             ├─ 保存与读取
             └─ Renderer / GameAudio
Blender 源模型 → GLB → Three.js 战场
Vite 打包 → 含模型、音乐和语音的 PLAY.html
JavaScript + Three.js + Blender + PathFinding.js + Web Audio + Vite。离线试玩不需要安装这些开发工具。

举个小例子：运输容量不是按“人数”随便塞，而是按步兵与车辆的权重计算。核心逻辑来自实际代码，完整的装载规则还会检查阵营、单位类型与装卸位置。

transportLoad(transport) {
  return (transport.passengers || []).reduce((total, id) => {
    const u = this.getEntity(id);
    return total + (u && u.hp > 0
      ? UNITS[u.type].tags.includes('infantry') ? 1 : 4
      : 0);
  }, 0);
}

目前 121 项自动测试通过，并做了桌面浏览器的补给、返场维修、混合运输、跨海、存档和无中文音色播报验证，也检查了 Linux 启动与用户菜单脚本。测试能帮忙守住规则，但真正的平衡仍要靠更多人玩，尤其是不同阵营、地图和长时间对局。
