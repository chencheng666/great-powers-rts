# 公众号玩家反馈整理与取舍

整理日期：2026-10-07。范围：三篇游戏文章的全部留言分页及折叠回复，并读到后台最近 30 天私信列表与 CAI 对话历史末尾。排除作者回复、自动回复、重复显示、纯支持留言与非游戏问题。未把用户昵称、头像、后台登录信息或私信原文批量公开；以下是游戏需求的归纳，不是私信转录。

这次重点感谢 CAI 的持续试玩和复现描述；林提出画质问题，丫提出联网，星空的天马和萬泉提出老 RTS 的玩法参考，W、Sam™、春风不语提醒下载入口不清楚。建议不是简单照单增加火力，采纳需有公平成本、反制、旧存档兼容和可验证结果。

## 本版采纳

| 反馈／问题 | v0.7.0 处理与边界 |
| --- | --- |
| 突击兵靠兵营不回血、不补弹 | 兵营脱战停驻付费治疗及补弹；机器人继续原有充电规则 |
| 工厂只补弹不回血 | 工厂／兵工厂补充地面载具生命，整备等待生命与弹药恢复 |
| 只有空弹单位才能维修 | 主动返场不要求空弹，右下补给按钮支持多选；空闲靠近合适设施也能补给 |
| 港口空闲舰艇自动维修补弹 | 保留已有付费修舰，并增加空闲泊港补弹；同样要求停驻、脱战、供电和资金 |
| 巡逻指令 | 两点往返，遇敌自动交战，整备后恢复原巡逻；支持存档 |
| 装卸放右下更方便 | 加右下卸载／舰载机起飞按钮；装载仍右键点击运输单位，保留原面板入口 |
| 右下指令区域可隐藏 | 增加独立折叠按钮和展开状态，不占满战场 |
| 建造完成打断原命令 | 完成后留在生产面板，点击才进入部署；右键／Esc 退出部署不丢建筑 |
| 矿车挖完后不能手动操作／出售 | 矿车移动指令优先；可回收，按剩余生命返还半价，货物不重复计价 |
| 前车挡路时战车抖动 | 扩展同层已知停驻障碍的提前绕行；移动编队不反复互相当成固定障碍；保留桥梁拥挤回归测试 |
| 地球飞机造型不适合月表 | 七类原创空间飞行器模板；六类原有飞机改用月表推进舱、姿态喷口及功能模块；新电子机也有月表外形 |
| 潜艇潜航外观不清晰 | 未暴露时深蓝半透明外形；声呐探测／开火／受击后恢复完整模型；迷雾仍严格隐藏敌潜艇 |
| 鱼雷应有水面尾迹 | 水平水面尾迹渐退；去掉鱼雷燃烧火焰，不把鱼雷画成空中导弹 |
| 补给中的着陆飞机可被地面攻击 | 停驻机场整备时降至地表，坦克／炮塔可攻击；起飞后恢复空地克制 |
| 轰炸机飞到目标头顶垂直投弹 | 飞临近距投弹窗口，炸弹固定落点按时间下降；投弹后自动返场，保留脱战与付费整备 |
| 增加空中电子战压制防空 | 原创无武装电子压制机：230 范围，每 10 秒压制 2.5 秒；制空机与范围外防空反制，不是永久或全图瘫痪 |
| 大海图撤桥强化运输 | 新增无桥“跨海登陆战”，两岸完全隔离，信标移至可占领岸位，支持登陆舰和舰载机；旧远洋图保留双桥与旧档 |
| 车辆迷彩、亮蓝／红标识 | 三色迷彩材质与车侧亮色五角标识；敌我血条、选择环仍为蓝青／红，不随阵营混淆 |
| 地面建筑有防护网 | 本项目原创的兵营／两类工厂防护网与迷彩；月表建筑不改成地球营地 |
| 树穿过新建筑 | 施工范围清理装饰树石，不再留在屋顶内；不新增随机植被碰撞、不给某一方隐含建造限制 |
| 海陆接缝缺少立体感 | 增加岸坡侧面与现有浪线；仍为矩形规则水域，不声称已完成自然海岸和全局 45 度镜头改造 |
| 陆图太平，车辆上坡没起伏 | 增强镜像可视坡面，车辆按前后地表高度平滑俯仰；基地／主路平整，坡面无隐藏伤害加成 |
| 战车爆炸留弹坑 | 有限实例池显示焦黑中心与土石坑缘，逐渐清理；不是可改变寻路的动态地形 |
| 配音希望可选男声／女声 | 可选浏览器实际提供的中文音色，或强制内置中文电台；未内置额外女声，不保证所有系统都有女声 |
| 不知道怎样下载／GitHub 链接不可点 | 新文章明文给仓库、版本页、ZIP 完整地址；不把 GitHub 当作已上线国内镜像 |

## 合理方向，但不作为本版已实现内容

| 反馈 | 决策与下一步 |
| --- | --- |
| 联网、局域网、MMORTS | 先双人权威服务端，再公网房间／重连；大型持久世界不是这次单机更新的等价替换 |
| 全域屏障改成网络攻击，暂时不能操作、可自动还击、摧毁来源解除、小地图雪花 | 保留电子压制方向；暂不把现有防守阵营能力换成全图禁操作。先设计局部目标、预警、持续时间、费用及解除条件，再做独立规则选项 |
| 侦察兵改间谍、进入建筑放定时炸弹、工程师拆除 | 单独规划间谍—侦测—爆破—拆除系统；不能仅换黑西装就宣布间谍功能完成，月表侦察机器人也不应变成人类 |
| 间谍敌方视角伪装、受击暴露、泳装蛙人 | 与间谍和联网情报边界一起设计，服务端不发送真实身份泄密字段；本版未实现 |
| 所有车辆碾压真人步兵 | 不直接采纳“所有车辆”：会破坏步兵运输／反装甲价值。可研究有限重装单位的低速碾压和反制，避免血腥表现 |
| 军用机场／港口／指挥所外形参考 | 采纳克制的军用营地风格；不照搬第三方游戏素材，机场／港口全高精度重建继续迭代 |
| 撤机场，把歼-20等全部放航母 | 不采纳泛化舰载兼容；保留陆基机场，只允许游戏中定义的兼容舰载型，避免以现实型号名称误导玩家 |
| 用《真实战争》《破碎银河系》《铁锈战争》作为参考 | 参考联合兵种、情报与后勤的玩法目标，不复制商业代码、美术、音乐或配音；不是这些游戏的重制／授权续作 |
| 改名《明日》，强调和平 | 作为社区命名提案保留，暂不未经作者决定改仓库与品牌；认同热爱和平的表达 |
| 核武器预警用红警原警报音 | 可做原创预警；不分发权利不明确的原游戏录音。东风、核规则、协同无人机、超音速、空天／月球基地仍是路线图，不宣传为本版现役能力 |
| 统信／麒麟应用商店 | 保留离线包与 Linux 用户菜单；申请商店前需实机、架构、授权和审核材料，不声称已申请／获批 |
| 手机端 | 保留现有基础操作；当前优先桌面，暂不扩展手机新功能和展示 |

## 验证与发布

本版新增针对基地维修、巡逻存档、轰炸出击、着陆克制、周期电子战、无桥地图与月表几何的回归测试。桌面浏览器检查新界面、实际三维像素、WebGL 错误、菜单／保存和中文内置通道；离线包另行验证。

服务端未购买、国内下载未上线，不编造地址。将来明确公布域名、版本下载、校验值和对战开放范围；当前地址均为完整 GitHub 地址。
