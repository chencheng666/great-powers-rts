# 音效现状与武器接入清单（2026-10-26）

> 下文保留接入前的核查快照。后续实施及测试结果见[音效接入与验收](音效接入与验收-20261026.md)。

本轮读取用户提供的《大国崛起bug汇总(3).pptx》与聊天截图，对照上一版 PPT、当前 `cd888b4` 源码、官网 `/play/`、现有 2.0 离线包进行核查。完成核查与接入清单，尚未接入新音效包或修改游戏逻辑。

## 一、先确认现状

- 新 PPT 共 37 页，前 32 页文字与上一版一致，新增第 33—37 页。音频文件仍是原来的 1 个 WAV，没有新增音频素材；新增视频为飞机地面停放与起降示例。
- 当前源码和官网声音面板均有“战场音效”滑条；官网实际打开面板显示默认 50%。现有 2.0 免安装包的 `PLAY.html` 也包含该控件及音效代码。
- 目前武器音效只有三种基础合成：通用轻响、通用重响、激光。另有原创核警报和荣誉提示。项目音频文件主要是背景音乐及中文播报，没有按枪炮、导弹、引擎分类的完整武器音效库。
- 本地浏览器实测 Web Audio 为 `running`，13 种武器调用均测得非零波形。`Game.fire → events.shot → GameAudio.shot` 的坦克链路也有输出。这证明本机基础链路可以产生声音，不能据此否定玩家设备的无声反馈。
- 玩家“单机 2.0 音乐、语音正常，全部音效没有，设置里也看不到”的完整现象尚未复现。需要拿其实际包、浏览器版本和声音设置截图核对，不能直接认定是播放器、音量或旧版本问题。

源码入口：`index.html:28`、`src/audio-data.js:48`、`src/audio.js:217`。

## 二、已复现的漏音与错音

### 1. 联机投射物没有发射声音事件

`Game.fire()` 将战机、火箭炮、鱼雷、轰炸机等交给 `launchProjectile()`；后者调用本地 `events.shot`，没有生成可传给客户端的发射音效事件。服务器创建战局时不接音频回调，客户端又只根据 `shot/muzzle` 等效果播放声音。

通过 `Game → battleView → OnlineGame.apply` 的实际快照转换复现：

| 测试单位 | 投射物 | 客户端发射声音 | 普通命中后的声音 |
| --- | --- | --- | --- |
| 步兵 | 无 | 有 | 当前仅发射声 |
| 坦克 | 无 | 有 | 当前仅发射声 |
| 战机 | 有 | 无 | 无 |
| 火箭炮 | 有 | 无 | 无 |
| 潜艇 | 有 | 无 | 无 |
| 轰炸机 | 有 | 无 | 无 |

源码入口：`src/game.js:976`、`src/modern-combat.js:173`、`src/online-game.js:60`。这是目前已定位的明确缺陷，但不能解释单机的全部无声反馈。

### 2. 发射、命中、损毁没有分开

普通投射物命中会生成 `explosion`，但没有对应音频回调。车辆、舰船和建筑损毁也缺少通用独立爆炸声音事件。当前爆炸往往只是画面，不是声画配套。

核打击单独触发了声音，但复用轰炸机的声音类型；上一轮间谍爆炸的专用触发仅在本地逻辑新增，还没有完善联机映射。

### 3. 武器音色归类不准确

- 弹道发射车、反导车、直升机、战机、舰载机、航母、月面电磁炮等多数走通用轻响。
- 潜艇鱼雷走通用重响，听感更像地面开炮。
- 巡逻艇、护卫舰、驱逐舰没有按实际武器事件区分舰炮、导弹和反潜武器。
- 联机维修效果也会触发 `shot('repair')`，随后落到通用轻响，存在“维修像开枪”的错误。
- 所有武器共用一次 60 毫秒的全局限频。密集交火时多个单位会互相吞声音，需要按声音类别、声部数量和优先级管理。
- 声音设置只有“试听中文”，没有“试听音效”，不利于玩家单独判断音效通道是否工作。

## 三、应接入的武器声音

先按武器类型共用声音，不必为每个国家、每辆车各做一套。

| 优先级 | 单位或武器 | 需要的声音 | 当前缺口 |
| --- | --- | --- | --- |
| 第一批 | 步兵、机枪 | 短点射、连射批次、轻型命中 | 只有很短的通用噪声，缺少清楚的枪声轮廓 |
| 第一批 | 主战坦克、炮塔、特色重装单位 | 炮口爆鸣、装甲命中、车辆爆炸 | 通用重响可作占位，需分开发射与命中 |
| 第一批 | 防空车、反导车 | 按实际攻击方式区分防空炮或导弹发射、拦截爆炸 | 反导等仍像轻型枪声，缺拦截反馈 |
| 第一批 | 火箭炮、巡飞弹、常规弹道发射车 | 连续发射批次、助推喷射、飞行掠过、地面爆炸 | 发射声混用，联机发射和命中漏音 |
| 第一批 | 战斗机、攻击机、舰载机 | 导弹发射、对空或对地命中 | 发射与命中未分开，舰载型与地面型音色不统一 |
| 第一批 | 轰炸机 | 投弹释放、延迟落地爆炸 | 应在落点响爆炸，不能把投弹声直接当作爆炸声 |
| 第一批 | 巡逻艇、护卫舰、驱逐舰 | 舰炮、舰载导弹、反潜攻击、水面命中 | 按实际攻击事件分配，不给所有舰艇统一套炮声 |
| 第一批 | 潜艇 | 鱼雷出管、水下爆炸、探测提示 | 鱼雷不能沿用坦克炮声，探测提示只在有相应事件时触发 |
| 第一批 | 武装直升机 | 机炮、导弹发射及命中 | 当前为通用轻响；旋翼另列持续声音 |
| 第一批 | 攻击无人机、巡飞弹、蜂群 | 小型武器或弹药释放、命中 | 需要与步枪、战机区分，蜂群限制同时发声数量 |
| 第二批 | 激光、电磁炮、月面机器人 | 激光束、充能、电脉冲、机械命中 | 激光已有简易合成，电磁炮及机器人需独立设计 |
| 第二批 | 核规则 | 发射助推、一次警报、落地爆炸与余响 | 已有原创警报，发射与爆炸仍需独立类型，不复用轰炸机 |
| 第二批 | 航母攻击编组 | 舰载机离舰、着舰、回收或损失提示 | 不应让航母派飞机时响成普通轻型枪声 |

### 持续声音及动作反馈

这些不是“武器开火声”，但直接影响玩家对单位是否在工作的判断：

- 坦克与履带车辆：发动机、履带行驶、停止淡出；轮式车使用轮式行驶声。
- 战机与运输机：引擎、滑跑、起飞、低空掠过、接地。停机后不持续播放飞行声。
- 直升机：旋翼启动、稳定运转、落地逐渐停转。
- 无人机：较轻的电机声；大批单位按距离合并和限声部，避免嗡鸣淹没战场。
- 舰船：低频动力、行船水声、靠泊；潜航另用水下层次。
- 建筑与保障：生产完成、装卸、补弹、维修、拆弹和设施爆炸。
- 死亡与碰撞：飞机坠落、车辆撞击、舰船沉没。碾压音效等到玩法确认后再接，不先做一声提示来冒充实现。

持续声只对已知、可见或己方单位播放，并随镜头距离衰减。不能通过战争迷雾外的引擎声泄露敌军。舰船和无人机的持续声不能按每个单位无限叠加。

## 四、接入顺序

1. 先修发射、命中、损毁的单机与联机事件，区分维修事件，补“试听音效”和小窗口可滚动的设置面板。
2. 再做第一批武器分类声与小、中、大命中爆炸，统一音量和限频，避免背景音乐遮住短促音效。
3. 加发动机、旋翼、履带和水声等持续循环，明确启动、移动、停止、损毁时的淡入淡出。
4. 最后做弹头阶段、着舰、沉没、机器人等专属细节；分别验收官网、离线包和联机。

验收应覆盖暂停、后台、静音、音效为 0、断音后恢复、同一快照重复到达、离线 file://、多单位同时交火及迷雾过滤。不能只看音乐和语音能播放就判音效通过。

## 五、素材有没有着落

有两条可推进的来源，但尚未集成为新音效包：

- **原创合成**：现有 Web Audio 已能产生非零输出，可以扩展枪炮、导弹、引擎与电子音，避免所有武器共用同一种“嘭”。这属于游戏化声音，不冒充真实武器录音。
- **已核对官方页面的 CC0 候选库**：Kenney [Impact Sounds](https://kenney.nl/assets/impact-sounds) 标注 130 个文件，可供碰撞、金属命中等素材筛选；[Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds) 标注 70 个文件，标签含科幻、太空、引擎，可供电子及科幻单位筛选。两页均标注 CC0。尚未逐个试听或下载，不宣称这些包已覆盖坦克、鱼雷和所有真实武器。

聊天中“把淘声网的声音录下来”的话属于素材建议，本轮没有据此录制或搬运音频。第三方素材采用前仍应核对具体文件的来源和许可，并随项目保留清单。

| 页码 | 新反馈 | 判断 |
