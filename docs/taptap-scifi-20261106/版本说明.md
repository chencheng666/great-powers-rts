# 星港演习：独立科幻战术版

这是《大国崛起》的长期维护发行变体，使用同一基础引擎，保留官网原版，数据、存档命名空间、模型与音乐资源独立。审核前后使用相同包体；没有审核专用开关、远程配置或后续恢复原版内容的机制。

## 本版范围

- 五个虚构工程组；子午星港和月海晶矿区两张月表地图。
- 机器人、原创程序化悬浮机甲和穿梭机；不包含现实国家和装备模型或核武器玩法。
- 基地建造、电网、晶矿采集、生产队列、三档难度、三种胜利目标、引导、图鉴及本机战局存档。
- 两首原创器乐沿用项目自制音轨，发行名称为《星港启航》《群星航迹》。不分发《国际歌》或外部商业录音。
- 本地单机，不连接玩家统计、故障上报、账号、反馈或联机服务；存档、荣誉和声音偏好仅在当前设备保存。独立 CSP 阻止网络 API 和远程媒体。
- 移除原版实时装备库、背景战斗视频、外部下载导航、核威慑 UI 与实际实现；构建遇到现实模型、视频或非白名单音轨直接失败。

## 构建与发布

1. `npm ci`
2. `npm run package:taptap-scifi`
3. 检查 `releases/taptap-scifi-20261106/构建报告.json`，把精确大小和 SHA256 对应到下载清单。
4. ZIP 顶层仅 `Starport`，包含 `index.html`、项目许可证、第三方许可证和隐私说明。
5. `npm run build && npm run stage:taptap-scifi`
6. `python3 scripts/package-tested-web-release.py <发布编号> --package=packages/Great-Powers-Starport-v3.0.0-TapTap-r3.zip`
7. 沿用服务器备份、无进行中对局、摘要校验、原子切换与回滚流程。官网原版入口及原安装包不替换为科幻版。

`variants/taptap/build-plugin.mjs` 为发行构建与引擎回归测试共用的变体定义。调整基础引擎后必须重跑两张地图、五个工程组的开局、存档恢复和禁用能力检查。

## 素材与许可

月表设施与机器人来自本项目原创 battle-library 的裁剪副本；穿梭机使用本项目程序模型，悬浮机甲在变体中独立生成。月表地表沿用项目已有 AI 辅助生成纹理，不表示考古或地质实物。三方运行库许可证随包附带，完整原版资产来源保留在 ASSETS 文档中。

## 验收边界

2026-11-06：637 项自动测试通过，实际 Chrome 验证两张地图开局、生产队列、选择与右键指令、配乐切换、存档恢复，390×844布局无横向溢出。录屏为真实20秒核心操作，截图来自本次包体。未完成全部 Android、iOS 和 TapTap 真机容器测试，不能据此承诺全设备兼容。

TapTap 原审核意见仅写“敏感题材”，没有指出具体触发内容；上述改造不等于平台承诺接纳，须以重新审核结果为准。上传、绑定、提审、审核通过与正式上架分别核验。

补充：r2在游戏首页直接披露固定的AI辅助月表纹理，隐藏不可用的呼号编辑入口，分别保存历史r1与当前r2发行文件。

公网试玩与商店使用同一变体插件和游戏源码；公网按模型、音轨与脚本独立缓存资源，商店仍使用完整离线单文件。两种封装均不连接游戏统计与账号服务。

r3进一步禁止原版第三方模型与材质导入，替换共享渲染模块的旧模型LOD助手，消除未使用的URL常量；最终科幻网页仅分发星港自有GLB。此前r1/r2候选不作为当前送审包。正式宣传插画使用imagegen另行设计，实际游戏截图与录屏仍保留。
