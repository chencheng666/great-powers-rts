# 走向2.0：指挥与反侦察迭代

状态：本地开发与验收完成，未标正式2.0，未重新发布下载包或更新服务器。既有积分、荣誉和存档版本保持不变。

## 连续航点

- 选中部队后按住Shift右键追加移动航点。选择攻击移动后，Shift左键可追加攻击移动；最多8个待执行航点，当前正在执行的任务不占这8个位置。
- 空闲部队立即开始首段，行进中的部队保留当前任务。下一段只有在当前任务结束后才开始；自动返场整备保留当前任务与未执行计划，无人机不会在中间航点结束时抢先返航。
- 当前避障路线与后续计划段分开显示，主路线标注顺序编号。后续虚线只是玩家规划，不冒充已经计算好的未来避障结果；真正执行时仍使用当时的地形与已知障碍寻路。
- 选择面板的清空按钮带队列数量，点击仅清除待执行计划。普通新命令替换整个计划；停止清除当前任务与队列。巡逻是循环任务，首版不允许在巡逻后追加无法轮到的航点。
- 首版只排队移动与攻击移动，不包含连续占领、登船、部署或对特定目标的攻击任务；不会透视追踪未来的敌军。完全封闭的地形仍可能使当前航点不可达，不通过瞬移完成路线。
- 编队的后续落点沿上一段计划终点重新定向，保持单位独立落点。舰艇遵守水域，后勤经济运输不响应作战航点，运输中的乘员不能追加路线。
- 单机存档保存队列并兼容缺少此字段的旧存档；非法类型、越界、非有限坐标、错误字段及超长队列被拒绝。重复选中编号不能绕过上限。

## 反侦察控制与模型

- 机动反侦察站默认开启，可手动切换。选择面板区分正常遮蔽、主动关闭、停车展开、缺少雷达链路、电力不足、瘫痪和运输状态；开关开启不等于设备一定能工作。
- 设备开启、停稳一秒、雷达存活且电力充足时，320范围内遮蔽敌方卫星情报；移动、停用或失去保障后不再生效。直接侦察和前沿雷达仍能突破，不删除已经探索的地图，不变成全类型隐身。
- 有效覆盖圈与停用覆盖圈采用不同颜色。三维桅杆和阵列有独立关节，收拢／展开平滑过渡；不增加每帧生成的模型或粒子。仍属于原创简化模型，不宣称真实装备性能或高精模型。
- 联机工作状态由服务端提供，不让客户端根据敌方隐藏电网自行猜测。敌方可见模型仅展示停车展开等外观，不公开设备开关、保障状态或后续命令。

## 联机与界面

- 队列追加、清空及反侦察开关都通过权威服务端执行；不能通过伪造编号操作敌军。新增参数只接受布尔值，重复实体编号在服务端去重。
- 敌方快照和淘汰观战视图不包含航点队列、反侦察开关或工作原因。己方客户端只提交指令，等待快照更新，不本地决定设备是否生效。
- 选择面板按队列数、开关与工作状态变化刷新；不必反复重新点选单位，也不每帧重建整个面板。队列按钮使用固定尺寸图标与数量角标。

## 本地验收

- `npm test`：382项通过、0失败，比上一批增加13项。
- `npm run build`：通过，仍保留既有的大体积主包提示。
- 真实双WebSocket会话：追加、清空航点、反侦察开关、敌方越权拒绝、重连与结算回归通过。
- 浏览器原生鼠标／键盘：Shift追加两个航点，面板数量为2；点击清空后当前移动不变。重新安排后坦克依次到达三个航点，最终当前任务和待执行队列均为空。
- 浏览器反侦察：显示“卫星遮蔽生效”；关闭后桅杆收拢比例约0.166并显示“已关闭”；开启但断电时，按钮仍为开启，实际状态明确为“电力不足”，恢复供电后重新生效。
- 1600×1000画面采样1343种颜色，无WebGL错误、无未捕获页面异常；1280×800及390宽基础检查无横向溢出。窄屏仅作基础回归，本轮继续以桌面为主。
- 截图、报告保存在本地 `releases/v2-command-intel/`。复验脚本为 `scripts/verify-command-intel.mjs`，需在专用Ego Lite验收空间运行，不要对正在游玩的对局执行。

这些结果不是自然完整对局、六方高压长局、弱网或跨国产硬件验收，也不等于竞技平衡已完成。
