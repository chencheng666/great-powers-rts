# 大国崛起桌面版 · 构建与兼容性

Tauri 2。游戏资源使用 `frontendDist: ../dist` 内嵌，单机不依赖 Vite、Node 或远端首页。联网按钮打开独立在线 WebView（现有试玩服务器），需要网络；该窗口不具备本地文件/备份命令权限。单机与联网窗口的身份、存档分开。

新增原生全屏、系统存档导入/导出、应用数据目录备份（manual/auto及上一份）。导入后仍用游戏存档验证器检查。原网页单机/联机功能继续保留。网页浏览器存档不自动迁移：先从网页导出JSON，再在桌面导入。

## 本地构建

Node >=22.16、现代Rust、当前平台Tauri系统依赖：

```sh
npm ci --registry=https://registry.npmjs.org
npm test
npm run desktop:dev
npm run desktop:build
```

Windows需MSVC构建工具及WebView2，NSIS配置`offlineInstaller`将官方WebView2安装运行时随包提供（包体明显增加）；不要改成跳过运行时检测。macOS需Xcode命令行工具/SDK；Linux需WebKitGTK4.1、GTK3、libxdo等。系统WebView必须能创建WebGL2上下文（Three.js r186）。

## 发行目标与真实边界

| 目标 | 构建路线 | 验证边界 |
|---|---|---|
| macOS Apple Silicon ARM64 | Mac本地或macOS CI，app/dmg | 当前计划目标；构建、运行及断网检查结果见发行记录 |
| macOS Intel x64 | macOS CI交叉构建，app/dmg | 构建不等于Intel真机运行 |
| Windows10/11 x64 | Windows CI，NSIS exe | 包含离线WebView2安装器；Windows真机待验证 |
| Linux x64 | Ubuntu22.04 CI，deb/AppImage | glibc/系统WebKit与GPU须兼容 |
| Linux ARM64 | Ubuntu22.04 ARM CI，deb/AppImage | ARM机器构建；不能用x64产物冒充 |
| 麒麟/统信UOS | 上述Linux架构产物按版本测试 | 尚无这些系统真机验证，不保证全部发行版；缺WebKitGTK4.1或WebGL2不能运行 |
| 龙芯LoongArch/申威SW64 | 未提供构建 | 不声称支持 |

GitHub工作流覆盖五种架构目标，触发方式为`desktop-v*`标签或手动运行；发行先创建草稿，所有产物及校验通过后才公开。CI成功不等于真机验证。此文的目标列表不是已交付结果，最终发行记录按产物分别列状态。

macOS实验包使用官方支持的ad-hoc签名（无Apple身份/公证）；Windows尚无代码签名证书。不关闭系统安全、不移除隔离属性、不承诺无警告安装。需要正式公证/签名时，应由用户提供已有合法开发者身份与证书，不建立账号或购买。

## 数据与连接

应用数据目录通常为macOS `~/Library/Application Support/cn.greatpowers.rts/`、Windows `%APPDATA%/cn.greatpowers.rts/`、Linux `$XDG_DATA_HOME/cn.greatpowers.rts/`（默认`~/.local/share`）；实际以平台返回目录为准，备份在`saves`目录。文件选取由原生对话框决定，不向前端授予任意文件系统读写。线上窗口仅导航现有服务器，无本地IPC权限。试玩服务仍为HTTP，应避免输入敏感信息；尚未启用云存档或自动更新。

资料：[Tauri依赖](https://v2.tauri.app/start/prerequisites/)、[CI矩阵](https://v2.tauri.app/distribute/pipelines/github/)、[Windows运行时](https://v2.tauri.app/distribute/windows-installer/)、[macOS签名](https://v2.tauri.app/distribute/sign/macos/)。

## 服务器下载发布

下载页为 `/downloads/index.html`。构建产物放入 `dist/downloads/packages/`，运行 `node scripts/download-manifest.mjs dist/downloads/packages` 生成上级 `manifest.json`（SHA256与字节数从真实文件读取）。无产物时不显示下载链接。安装包文件名包含版本和架构，禁止覆盖不同内容的同名历史包。发布脚本仅将安装包移至 `/opt/great-powers/downloads/packages`；下载页与清单保留在版本目录随原子切换及回滚生效。
