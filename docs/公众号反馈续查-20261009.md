## 本轮完成

| 反馈 | 改进与边界 |
| --- | --- |
| 潜艇回港补弹不顺畅 | 原有 R 返港流程继续保留。新增右键己方港口进入指定港口整备，避免普通移动停在补给区域外；多个港口独立分配泊位。测试双方混合舰队的部分耗弹、损伤恢复与港口失效改投。不能据此断言所有历史补弹问题均已复现或修复。 |
| 潜艇靠港应浮航，暴露不应整个艇体浮出水面 | 港口整备显示上半艇体；潜航轮廓沉入水下并缩薄，水面舰艇正常遮挡。港口浮航敌艇仍须先进入己方视野，不穿透战争迷雾。现有反潜武器克制规则不变。 |
| 鱼雷从艇尾发出 | 出管点改到艇首，先沿艇身方向运行，再以有限角速度转向追踪目标。保留伤害、弹药、射程和既有水线轨迹；仍为游戏化制导，不是真实鱼雷模拟。 |
| 两架运输机或两艘货船同时进入 | 同侧同类线路一班在途，前班返程退出后才放行下一班；旧存档积压机船串行等待，销毁首班后后班可接续。不能追补多班或重复到账。 |
| 舰艏、舰身拼接明显 | 巡逻艇、护卫舰、两种驱逐舰模型、集装箱船与航母水线船壳使用连续曲面和圆滑过渡。保留原舰桥、武器与航母斜角甲板；登陆舰保持平艏装卸结构。 |
| 运输机机身偏细 | 常规重型运输机、后勤运输机采用宽体流线机身，保留机翼、发动机及原单位参数，不修改月表航天器。 |
| 维修建筑提示不醒目 | 新增完整开口扳手、呼吸动画、缺钱等待色，布局避开血条与操作面板。 |
| 雷达、发电设施应有动态 | 常规雷达扫描天线旋转，发电机加入轴心对齐的旋转风扇；暂停后停止推进，断电雷达停扫。月表相控阵设施暂不添加机械扫转。 |
| 舰船与陆地建筑观察角度不协调 | 立体正交视角调整到 45 度，树木图层随视角更新；保留战术视角。没有替换所有二维环境素材或改成自由旋转透视镜头。 |

后勤公平性：每批空运 720、海运 900，以及 36／60 秒最短间隔保持不变；改为单班放行后，实际收入受航程、受阻和返程影响，可能低于原来允许两班在途的版本。双方对称适用，不宣称经济节奏完全没有变化。月表采矿规则不变。

港口维修仍需资源、电力、停稳及脱战时间，不扩展为远海自动回血；港口浮航不会改变现有反潜伤害规则。老存档可继续读取，指定港口信息随存档保存，港口损毁后可改投存活己方港口。

## 保留在后续规划

- 完整机场滑行：停机坪、滑行道、跑道进入和等待调度需与飞机返场、部署和战斗指令统一，不能只画一段动画就宣称实现。
- 轮胎着陆音效、接地烟雾：需要与真实接地状态绑定，避免飞机盘旋时反复触发；本轮未加入。
- 港口和舰艇真实水面反射：需要选择平面反射或屏幕空间反射方案并验证海图性能，本轮仅改善透明水面遮挡，不是真实倒影。
- 更精细的人物、舰桥和航空座舱：现有模型仍是原创简化游戏资产，不是实装装备精准复刻。
- 国产系统安装包、应用商店：保留免安装网页主体验；后续另行评估包装和上架要求。
- 游戏命名建议“明日”：作为命名投票意见保留，不擅自修改项目名称。
