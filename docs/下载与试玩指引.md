# 下载与试玩指引

目前提供电脑浏览器单机与昵称游客双人对战，支持 Windows、macOS，以及能够运行兼容 WebGL 浏览器的 Linux 环境。银河麒麟、统信不同版本与浏览器仍需实机验证，不承诺全部设备兼容。国内下载服务器尚未上线。

公网试玩与联机测试：http://43.135.186.21:8088/ 。该服务器位于硅谷，2026-10-09 已同步 v0.8.0 网页与对战服务。离线 v0.8.0 包为单机；同版本源码含对战服务，局域网方式见 [联机指南](联网加入修复与局域网指南-20261008.md)。

## 下载哪个文件

发布页面完整地址：

https://github.com/chencheng666/great-powers-rts/releases

打开最新已发布版本的 **Assets**，选择名字类似 `Great-Powers-RTS-v0.8.0.zip` 的试玩包。不要选页面自动提供的 **Source code (zip)**，后者是开发源码，不是免安装试玩包。

当前 v0.8.0 离线包完整地址：

https://github.com/chencheng666/great-powers-rts/releases/download/v0.8.0/Great-Powers-RTS-v0.8.0.zip

本包包含最新动作、海军、AI、战后复盘、图鉴与荣誉功能，具体见 [v0.8.0 版本说明](releases/v0.8.0.md)。GitHub 访问受网络影响时，可换网络稍后重试；目前没有另外可用的国内镜像域名。

## 打开游戏

1. 将试玩 ZIP 完整解压到一个文件夹。
2. 用电脑浏览器打开解压目录中的 `PLAY.html`，不要在压缩包预览窗口中运行，也不要单独移动该文件。
3. 首次打开输入昵称，选择地图、阵营与难度，点击“单机作战”。地图较大，可拖动画面或使用小地图定位；资料可在游戏内图鉴查看。

推荐先用“新兵”难度熟悉补给和生产。现代常规地图依赖外部运输收入，子午地图采用月表采矿；工程师可以占领油井、信标及新版本中的能源仓。

## 中文语音与进度

声音菜单中可以选择系统中文音色或内置离线中文。没有系统中文声音时选择内置音色，并点击试听；确认浏览器页面未静音，总音量与语音音量均非零。v0.8.0 包含内置男声、女声，均可断网播放。

详细排查：[中文语音使用教程](中文语音使用教程.md)。

更换浏览器、电脑、试玩包路径或清理浏览器前，导出战局存档。玩家荣誉档案与战局独立，新版本还需在荣誉界面单独导出备份。浏览器本地存储不是账号云存档。
