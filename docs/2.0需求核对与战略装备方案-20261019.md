## 二、新地图不是单纯变大

新增“战略纵深”，固定 **6400 × 4160**，不会再被纵深倍数放大。它是双人陆空战略实验场，不宣称比所有旧地图都大，也不替代远洋地图。

- 三条通路连接三个信标，北／南山体分开推进线，侧路便于绕后。
- 四处油井、四座能源仓、四处物资箱、两处回收场，左右镜像；双方经济、生产、单位基础规则一致。
- 保留可被拦截的空运后勤，不恢复常规战场挖矿；能源仓可延伸前沿部署。
- 侦察与争夺物资决定远程装备能否发挥；机场、雷达、电网、补给线都是可攻击环节。
- 新增装备先限定实验地图生产，避免一次改坏旧图平衡；F-22 外形用于已有西陆制空机。

## 三、组合与反制

| 进攻方式 | 反制方式 | 限制与决策 |
| --- | --- | --- |
| 直升机压制坦克 | 防空车、制空机、机场突袭 | 不能空战；六发导弹；机场付费整备，不能在空中由地面补给车回血 |
| 侦察引导弹道火力 | 区域反导、发现后疏散、猎杀发射车 | 1320 游戏射程、420 盲区、5 秒展开、固定落点、两发容量；飞行期间目标可离开 |
| 母机释放异构蜂群 | 战机猎杀母机，激光／防空／干扰处理子机 | 同时一架母机、两批任务舱、每批三架子机、同母机最多六架、24 秒任务窗口 |
| 卫星揭露战场 | 停驻反侦察站保护局部 | 反侦察需雷达和电力，移动失效；不能阻止近距直接侦察，不能抹掉地形记忆 |
| 反导阵地 | 断电、打雷达、装甲突击、消耗拦截弹 | 四发库存，一枚来袭弹通常需两次命中；不能替代常规防空、反无人机和对地火力 |

数值全部是游戏尺度。诱饵是可击落、占用自动火力的真实机体，不强制“嘲讽”，敌方仍可手动打高价值目标。母机使用攻击移动（A）执行任务，单纯移动和停止不放蜂群；子机限时退出，不独立生产、不补给、不无限复制。

各阵营都能生产基础战略职能；华夏使用东风／九天原型介绍，西陆使用阿帕奇原型介绍，其他阵营用原创通用名称，不给未核实的国家硬套型号。F-22 不凭名称获得无敌隐身，仍采用既有制空规则。

## 四、核威慑与大地图

建议保留常规玩法，再做**默认关闭、开局明确同意**的战略威慑模式。先把常规弹道与反导测稳，不加入“一键清屏”。完整候选规则见 [开发清单](../ROADMAP.md)。

候选设计是昂贵设施、约 240 秒准备、约 4500 资金、单局一次、约 20 秒全体预警、有限爆心衰减，以及有限弹药的多次拦截。摧毁设施、打电网、疏散分兵和破坏补给也必须有效。以上尚未实现，核防御不绑定“万能现实型号”。

先用战略图验证，不立即重开更空旷的超大图。实测行军太久时先增加前哨、争夺点和有效航路；多人海陆战略确有需要时，再设计专属出生点、经济与舰队目标。

## 五、精美画面必须有实机标准

1. **轮廓：**战术距离可分清战机、直升机、母机、发射车、反导与反侦察站；阵营色只是标识，不把整机涂成玩具。
2. **材质：**涂层、金属、玻璃、橡胶分开；面板和任务舱保留立体结构，按材质合批控制绘制数量。
3. **动作：**主尾旋翼分轴、弹道俯仰、尾迹与分层爆炸；发射筒举升、机场起降、传感器动作仍需精修。
4. **环境：**道路对应通路、岩体对应碰撞、资源不落进障碍；后续补区域建筑与地景叙事，不只加树填空。
5. **性能：**几何、材质、三角面数与合批自动测试之外，还要做约定硬件上的 120／240 单位持续交火，不能宣称所有电脑流畅。

## 六、到 2.0 的缺口和顺序

还缺：核威慑完整规则、挑战／战役、分支科技、连续指令、驻军／烟幕／可破坏桥梁等地图互动、关键事件回放、肩章方案落地、新装备联网长局、六方弱网／容量、全量模型精修、国产系统实机与签名发行。两个用途存档槽和战后数字不等于完整多档案／录像系统。

建议顺序：**常规战略原型 → 画面与操作精修 → 真人平衡／联网／性能 → 可选威慑 → 单机内容与平台发行**。不承诺未经验证的“画质顶峰”，以实机截图、连续游玩、帧时间和缺陷清单验收。完成后再统一更新 GitHub、离线包、服务器与文章。

- 高画质后处理正常启用、WebGL 错误为 0；主旋翼角度连续变化，模型不是静止贴图。
- 截图及机器验收结果位于 `releases/strategic-qa/`：包含开局、装备布景、F-22、AH-64、东风、九天图鉴和小桌面视口。装备布景是明确摆放的验收场景，不冒充自然实战或完整战役。
