# 光影层次、圆形地台与范围补给优化

状态：本地开发和验收完成，本说明随源码提交；本轮没有重新发布安装包或更新公网服务器。公众号内容未因本轮开发自动改动。

## 画面调整

- 立体视角保持45度俯角，增加30度水平观察角，建筑同时展示屋顶、正面和侧面；战术视角仍可切回原朝向。拖拽、缩放、点选投影、树木朝向与视口边界同步适配，不旋转真实出兵口或碰撞体。
- 生产建筑等设施增加低矮圆形工业地台，采用灰黄色混凝土、深色外沿和分段警戒黄标记。地台是三维圆柱实例，不是悬浮光圈；不改变建筑占地和通行规则，码头保留原有泊岸结构。
- 移除原有过度降饱和、压对比的地面处理，降低过强的均匀环境照明与白色轮廓补光，保留定向日照和接触阴影。增加土壤、植被色块与凹凸细节，降低地表灰白感。
- 飞机、直升机、任务母机等机体增加分区蒙皮、接缝、铆接、法线和粗糙度贴图；保留透明座舱与金属、橡胶差异。不增加每架飞机的绘制批次数。这仍是程序化简化模型，不宣称高精扫描或照片级画质。
- 树木正面贴片也参与环境光照，不再使用不受光照影响的基础材质。树仍是图片面片与交叉层次的混合表现，不是每棵树都更换成精细几何。
- 战斗焦痕和弹坑碎石的可见时间从35秒延长至180秒，仍最多保留80处且服从战争迷雾。不改变地形通行、伤害或存档中的战场地形。

| 补给车造价／生产时间 | 460／21秒 | 300／17秒 |

- 每1.25秒为保障圈内所有需要弹药的友军陆地作战单位各补一发，按缺弹比例分配有限库存与资金；部队不必贴靠补给车。
- 脱离受击3秒后，圈内伤员共享每辆车每秒24生命的维修总量；同一时刻多车不叠加同一单位的服务。库存、维修费和弹药费仍实际扣除，不能靠维修车持续无敌。
- 行驶中的补给车保留范围保障能力，手动移动优先；即使库存为空，玩家仍能命令它撤离。
- 自动保障优先圈内单位，只在附近800范围内寻找新的可达目标。不可达、隔海、山体阻隔、载具内乘员及海空单位不会获得穿墙或跨层补给。月表机器人沿同一范围寻找供电充电来源，不凭空获得常规弹药。
- 补给车寻路对整片驻军预留车宽，不再从停驻坦克间的过窄网格缝隙穿行；一段时间没有实际位移则暂时跳过目标，避免原地来回切换路线。
- 缺弹单位位于有效保障圈内时原地等待，补至一半且修复后恢复原任务，不与补给车相向追逐。没有可用保障、付不起相应费用时仍可回基地整备。
- 坦克可在更远距离交火，但仍短于巡飞弹车、火箭炮等远程单位；保持空地克制、弹药限制和双方／AI统一规则。战略核规则和反导车备弹未借此放宽。
