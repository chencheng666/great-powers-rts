# 首批开放资产接入验收

本轮为 1.3.1 代码基础上的本地画面迭代，未新建正式版本、推送 GitHub 或部署服务器。

## 实际范围

- 西陆普通坦克使用 Sketlux / yd 的 CC0 Abrams：统一比例和方向，拆分炮塔、炮管，保留循环履带；炮口闪光跟随新模型实际炮口，不改战斗判定。
- 西陆 F-22 使用 andertan 的 CC BY 4.0 模型：保留蒙皮颜色和法线贴图，整理朝向、透明座舱、起落架和弹舱；不套用到其他阵营。
- 港口使用 Poly Haven CC0 工业吊机，重做支架、金属屋面、护舷与货箱配色。货箱通过顶点颜色合批，原有码头主体仍维持 8 个材质批次；两组外部吊机额外共 4 个批次。
- 常规地图采用 CC0 草岩扫描地表；港口采用 CC0 磨损混凝土。颜色、法线和粗糙度分别加载，月表保持原有月壤。
- 所有资产本地打包，无运行时国外热链。各项载入失败时独立回退，缺少动作节点的错误模型也在载入阶段拒绝。

授权、原作者和修改说明在 `THIRD-PARTY-ASSETS.txt`；实际文件哈希与面数在 `assets/third-party/manifest.json`。游戏操作说明提供署名下载，离线包同时包含该文件和第三方依赖声明。

## 实机与性能

使用 Ego 浏览器、Apple M1 Pro、1188 × 706 战场视口；相同 120 / 240 单位混编场景，30 帧短采样。绘制统计使用相同的直接场景渲染口径，不包含全部后处理通道。

| 高画质场景 | 接入前 | 接入后 |
| --- | ---: | ---: |
| 120 单位绘制调用 | 4,032 | 2,289 |
| 120 单位三角面 | 3,987,756 | 1,029,681 |
| 120 单位渲染 CPU 中位耗时 | 17.1 ms | 13.2 ms |
| 240 单位绘制调用 | 8,221 | 4,854 |
| 240 单位三角面 | 7,779,076 | 1,885,439 |
| 240 单位渲染 CPU 中位耗时 | 41.5 ms | 31.7 ms |

120 单位帧间隔中位数为 32.6 → 34.0 ms，不能宣称帧率提升。240 单位的高、标准画质采集均出现约一秒的帧调度间隔；抽样分析以空闲时间为主，尚未确定浏览器调度原因，因此不据此承诺大军团稳定 FPS。这里只确认模型绘制负载和 CPU 渲染开销降低；长时间实机帧率、其他显卡和设备仍需后续专项验收。

实机展示场景通过游戏模拟生成，包括坦克实际移动／开火、F-22 空中编队、载有六个单位的登陆舰与新港机。为了观察模型，验收场景调整了编队位置、迷雾和测试生命值；不代表一局自然游玩的进程，也不改变正式规则。

## 构建与复现

1. `node scripts/fetch-open-assets.mjs` 下载所需公开源文件，先查阅各来源当前许可。缓存位于忽略目录 `releases/open-assets-source/`。
2. Blender 后台禁用自动脚本，执行 `scripts/build-open-assets.py`。转换包含网格校验、减面、部件分离及 GLB 导出。
3. 将源缓存的地表及混凝土三通道 1K JPG 复制为 `assets/third-party/ground-*.jpg`、`concrete-*.jpg`，执行 `node scripts/record-open-assets.mjs` 更新哈希记录。
4. `npm test`、`npm run build`；按 `scripts/capture-open-assets.mjs` 与 `scripts/verify-open-assets-browser.mjs` 的输入在同一 Ego 任务空间复核。
5. `npm run package:offline` 验证内联和署名分发。当前本地验收包约 64.18 MiB，未上传下载站或作为新正式 Release 发布。

本轮仍保留其他阵营、步兵、舰船与资源设施的原模型。地图布局、登陆点、碰撞、供电、资源、伤害和射程没有改动。后续优先寻找同等许可质量的国产主战坦克、舰船、步兵骨骼及港口完整模块，逐项比较后接入，不以低质免费素材凑覆盖率。
