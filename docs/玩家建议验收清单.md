# 玩家建议验收清单

更新日期：2026-10-06，公开版本 v0.4.0。感谢 CAI 与其他玩家长时间试玩、指出问题。本表区分已经交付、仍有提升空间与尚未实现，不用规划图冒充完成。

| --- | --- | --- |

| 步兵和战车有限弹药 | 已实现 | 持续射击消耗弹药，缺弹停止射击；维修补给车提供保障 |

| 登陆舰、轰炸机、运输机 | 已实现 | 大型海图造登陆舰靠岸混合装卸；实验室解锁轰炸机，雷达解锁运输机 |

| 甲板起降、空战转弯、导弹路线 | 本轮实现基础版 | 实际飞机升降起飞、返舰；制空飞机盘旋，导弹有限转弯与俯仰；火箭炮弧线、炸弹下落、鱼雷贴水区分。仍是游戏抽象，不是飞行模拟器 |
| 卫星剥开战争迷雾 | 本轮实现 | 雷达＋实验室、1000 资金、120 秒冷却、8 秒揭雾；敌方有预警，结束恢复实时迷雾，已探索地形保留；不能替代反隐与声呐 |
| 052D 与武器真实名称 | 部分实现 | 华夏驱逐舰新增 052D 原创简化模型，其余公开型号见 EQUIPMENT.md；并非每个单位都有精密专属模型 |
| 全屏、收侧栏、拖地图、建筑浮窗、出厂动画 | 已实现 | 顶栏图标／F／B，右键或中键拖拽，建筑点击查看信息，生产单位由设施出口出现 |
| 存档与返回首页 | 已实现 | 手动／自动、导入／导出、退出询问；新经济存档保存运输进度、舰载机状态和卫星状态 |

| 更精美模型和地图 | 持续改进 | 本轮新增后勤中心、货船、运输机、052D、航母，加入空投箱及连续岸线；现有混合渲染与模型精度仍有局限 |

## 本轮验证

- `npm test` 覆盖正常与月表经济、镜像运输、完成卸货单次计费、失去设施降级、断电／受袭阻止服务、混合舰队返港、真实舰载机登舰起降、卫星揭雾与旧存档兼容。
- 桌面浏览器验收使用实际 Game／Renderer，布置固定功能场景，检查舰艇修满和补弹、空海收入、飞机移动、卫星费用与时限、存档内容以及画布像素和 WebGL 错误；截图不是自然对局战报。
- 自动验证不代表竞技平衡、所有 Linux 设备兼容或大规模舰队性能已认证。欢迎在 Issues 提供地图、阵营、时间、设备和复现步骤。
