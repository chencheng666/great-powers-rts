# 粉丝后续玩法与统计（2.0.1）

- 普通遭遇战中，移动中的履带坦克真实接触敌方步兵可造成碾压；月表对应机器人沿用相同规则。友军、载具、建筑和装载人员不受碾压，静止车辆不凭空造成伤害。原有固定挑战维持已验收的战斗规则。
- 固定翼返场经过跑道滑行到独立机位，以45度停放；获得新任务时滑回跑道再起飞。每座机场最多安排6架返场机，机位满时等待；中途取消、机场损毁、存档恢复及对方快照均有保护。航母甲板停放模型也调整为斜列。
- 西陆同盟的战术运输机与货运机使用原创串列双旋翼外观及旋翼声，月表和其他阵营继续使用其各自模型，不变更载重与经济规则。
- 官网下载中心通过白名单跳转记录每个文件的本站下载次数；数据从本功能启用时开始，站外直接下载与启用前的历史次数不可回补。续传分段与HEAD不会被算作新的跳转。
- 网页、离线ZIP和新桌面安装包分别标记入口与构建版本。单机联网时按前台未暂停心跳上报匿名游玩时长；完全断网时正常游玩，未上报的长时离线时长不回填。旧安装包没有新上报代码，升级后才生效。
- 首次加载优先完成必要模型与材质，精细开源模型、码头细节及额外地表材质延后加载；当前战局已有模型不会中途闪换，下次创建单位或新战局可使用已加载的细节。网络速度和终端性能仍会影响首开。
- 官网扩大首屏和卡片的呼吸空间，手机端操作入口纵向排列；新增机场铺装范围清除树石。

测试范围和线上发布证据以最终交付记录为准。真实玩家明细、管理员口令和本地验收数据不写入仓库。
