# PPT 反馈优化与验收（2026-10-24）

来源：用户提供《大国崛起bug汇总(2).pptx》，共 32 页、8 段嵌入视频。前半部分标注 Windows 1.2 离线版，后半部分标注 Windows 2.0 离线版。已提取文字、渲染全部页面，并查看视频关键帧。原 PPT 未修改；其中玩家建议按当前实现与影响范围筛选。

本轮基于 `cd45bbe` 的 2.0 源码修补，完成本地测试、构建与 Chromium 页面验收。**尚未发布公网，也未重打 Windows 离线包。** 原有发布清单、路线图和其他未提交资料保留。

## 验证结果

- `npm test`：517 项全部通过，零失败。新增 10 项回归；原有轰炸机“一弹返航”的断言按本轮行为修正，潜艇和警报断言同步更新。
- `npm run build`：通过。仍有原有的大体积 chunk 提示。
- 实际浏览器：本机 Chromium、远洋战区、受控战局；通过真实右键输入检查移动与菜单，固定步长推进逻辑和动画，不提交战绩、不连接公网房间。
- 战机到达命令点的最近距离为 2.54 世界单位，单帧转角不超过 0.0475 弧度，撤离期间弹药保持 9；桨叶减速至 0。
- 浏览器中轰炸机经 28.55 秒完成四枚炸弹的多轮飞越投放，自动返场；每个未返场逻辑步的位移至少 7.1 世界单位。战略弹头显示缩放实测为 2.2。
- 航母尾迹距模型中心 100 世界单位，水平贴水绘制；截图确认船尾可见。
- 潜艇在未暴露及暴露状态均低于水面，暴露只增强蓝色轮廓；截图确认两种状态均可辨。
- 真实 Web Audio 节点：提前阶段静默，最后 11 秒单次播放，`loop=false`，重复同步保持同一节点。
- 浏览器异常列表为空，WebGL 错误码为 0。
- 本轮未进行 Windows 原生离线包、长时间多人联网或公网发布验收。
