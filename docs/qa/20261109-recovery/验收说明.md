# 错误日志与本机等级保护修复

构建：20261109-recovery-r2。接续当日防空、音乐与印章更新，范围为网页、官网、国内双人与六方共用服务。桌面、ZIP和商店包保持各自版本，科幻版冻结内容保留。

## 根据真实后台日志定位

近期可定位错误包括图形连接中断、战场画布空节点、动态模块和纹理载入失败。旧脚本坐标对应拖图控件的canvas.classList与画面标记的canvas.parentElement.querySelectorAll；补上原画布复位和已销毁渲染器的回调保护。日志只说明节点访问失败，不把未知的移除来源写成已确认根因。

- 默认流畅画质，仍尊重玩家显式保存的画质选择。关闭不必要的持久绘制缓冲；图形连接中断后保存单机战局，并将下一次尝试设为流畅画质。
- 月表表面纹理在重试耗尽后使用本地生成的灰色备用纹理，不阻塞已经载入的核心模型。缺失核心模型仍明确报错，不伪装成功。
- 游戏外注入路径的脚本／样式不再记为游戏资源故障；游戏assets/src路径的真实错误继续上报。断线错误补充固定代码，不记录玩家内容、地址或完整错误原文。
- 保留原有视频海报降级与手动重试；硬件未开放WebGL时继续提供设备指引，不承诺软件能够消除驱动或浏览器外部故障。

## 等级保护

荣誉等级属于本机浏览器档案，与服务器的联机战绩和访问统计不同。现有统计不足以还原任一玩家完整原积分和等级，不按同名访客拼接或补发分数。

- 旧有效荣誉首次读取建立本机副本；新结算保留有效副本和上一个有效版本。辅助副本配额不足不把已经写入的主成绩误报为失败。
- 主记录缺失或损坏可读取有效副本，损坏原文先另存，失败则不覆盖；主记录和所有副本都损坏时保持报错，不静默归零。
- 荣誉档案增加“找回等级”，检查本机副本及官网另一个域名。分叉旧档案由玩家核对确认后替换，保留现档，不自动叠加积分。
- 清除浏览器全部数据、更换浏览器／设备、改变离线文件位置后的旧记录仍可能需要从原入口导出；本轮没有引入按昵称云恢复。

## 验收

651项全量测试通过，生产构建通过。另有6项恢复专项测试通过，涵盖缺失／损坏恢复、旧档显式替换、副本配额不足、原画布复位、注入资源过滤、跨域消息来源校验。

浏览器主动移除原战场画布后已复位。调用WEBGL_lose_context模拟图形中断，出现恢复提示，自动战局存在；恢复连接后点击流畅画质恢复，画面恢复且时间保持01:58，preserveDrawingBuffer=false。荣誉找回入口在无候选时给出原浏览器／原网址导出指引，不声称恢复成功。浏览器屏蔽月表纹理请求后，113个模型仍载入成功，并使用128像素本地灰色备用表面。

具体玩家历史档案仍需原设备／原入口证据；不能以防护功能完成代替本人历史等级恢复。
