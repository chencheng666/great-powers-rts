# 官网更新区网格修复

原因：新增1200像素宽的防空展示图片进入三列`1fr`网格，轨道默认的自动最小宽度采纳了图片的固有尺寸，中列撑到1200像素，其余两列缩至39和26像素，文字逐字换行。本次修复图片加载后的实际布局，不能仅以资源成功返回代替视觉验收。

修复：列轨道使用minmax(0,1fr)，卡片min-width:0，展示图通过外部CSS限制在卡片宽度内。桌面三列、701–1100像素两列、窄屏一列。移除图片行内样式，标题下链接按内容宽度排列。

验收：生产构建与git diff --check通过；浏览器分别在390、768、1024、1440像素视口滚动至图片，等待图片真正载入后检查，所有卡片同宽，图片不超出卡片，页面无水平溢出。1440像素卡片从39/1200/26错误宽度恢复为三列约378像素；更新区网格高度约812像素。已查看桌面和窄屏截图。

发布使用既有静态前端流程，只新增哈希资源并备份、切换页面，保持游戏进程与运行对局。release.json作为可选页面同步，以便资源摘要对应实际官网文件。公网验收另行记录。
