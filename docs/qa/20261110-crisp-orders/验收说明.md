# 3.2.2 目的地标记与画面清晰度

构建 `20261110-crisp-orders-r1`，接续已上线的3.2.1。根据用户截图修正目的地标记和默认画质。

- 原来的空心圆与悬空旗形改为沿路径末段方向的实心小箭头，箭尖落在实际目的地；路径与箭头衔接，浅色地面加深色细描边。近距离重叠落点不重复绘制箭头，连续航点保留编号。
- 默认流畅画质在高分屏、非密集战斗中从1倍提升至最高1.5倍；精细最高2倍。两档均申请轮廓抗锯齿，避免从流畅切精细后上下文无法补启抗锯齿的问题。
- 移除地面贴图额外的1.4像素模糊，保留压低地面色彩对比以突出部队的设置。
- 视口内超过144个单位时，流畅回到最高1倍、精细最高1.25倍，阴影更新间隔50毫秒；大视口控制超采样像素，最低保持原生1倍。未改变寻路、碰撞、战斗数值、存档和联机协议。

本地回归：674项测试全部通过，生产构建通过。Ego Lite实际WebGL高分屏检查得到流畅1.5倍、精细2倍，连续来回切换两档均保留抗锯齿；连续航点1/2/3可见。120单位受控交战180帧的CPU更新与渲染调用耗时中位17.1毫秒、P95为22.1毫秒；此数据不等于GPU帧率或所有设备流畅保证。

240单位密集场景的50次受控同步采样：视口237–240单位，渲染比例为1、抗锯齿开启，中位45.9毫秒、P95为49.8毫秒。旧渲染器同类场景约44.5/49.0毫秒；随机交战状态有差异，这不是严格帧率对照，密集模拟仍有性能瓶颈，不能宣称240单位稳定60帧。原像素与阴影限制继续生效。
