# 空军模型与飞行表现验收

构建：20261111-airforce-r1，网页版本3.5.0。

本轮实际下载并采用 Captain_Ahab_62 发布的 CC0「fighter jets」中的四款模型：F-111用作轰炸机外形，EA-6B用作电子战机外形，F-14与A-6E用于西陆舰载制空与攻击编组。统一方向、尺寸、材质和喷口；配置近远景LOD，舰载机另有对应的后掠／折翼停机简模。四个GLB合计445896字节，所有资源从本站加载，无需登录素材站。

华夏制空机补充翼身过渡与进气口，对地机使用独立双发原创外形。其他已有具体型号的机体、直升机和运输机保留，避免用不匹配的经典战机冒充。爱给网收费候选和Sketchfab候选未下载；另查的F-15采用OGA-BY许可，本轮未分发。

尾焰按机体局部喷口定位，运输机无加力火焰；停机、登舰和失能时熄焰。低高度滑跑不侧倾，重机与进场机减小侧倾。异步加载失败保留备用模型，成功后更新已存在飞机和甲板显示，不重置单位或命令。原有尺寸表、三层飞行高度、24架舰载容量、最多6架出动及平衡参数保持原规则。

本地全量699项测试通过，生产构建通过。Ego Lite真实入口开局后核验四款外形、24架满甲板和逐机出动；起飞队列24架中6架在外、18架在舰。受控149单位场景包括120架新增飞机：40帧样本的主线程渲染调用中位3.3ms、P95 4.2ms，实例合批20组，262658个三角形；该数据只代表本机受控场景，不等于实际联网帧率或所有设备性能。WebGL错误为0，图形上下文有效，未记录页面运行错误。

可复现转换：先下载来源ZIP至releases/open-aircraft-source/oga-fighter-jets/并解压，在Blender禁用自动脚本模式下运行scripts/build-free-aircraft.py。来源及摘要见素材筛选.json和素材目录来源与修改.txt，几何预算见geometry-report.json。

本文件记录发布前验收；Git同步与生产部署结果另行回读后记录。测试场景与截图仅位于被忽略的qa目录，不进入真实运营数据。
