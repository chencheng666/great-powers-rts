# 3.1.1 指挥与兵种辨识优化

构建：20261110-experience-r1。范围为官网、网页及国内双人／六方共用服务；桌面、离线下载、TapTap 科幻变体保持独立发行。本轮不宣称完整4.0或新的目标系统兼容认证。

## 改动

- 首页提供陆战入门、海陆协同、据点争夺三个推荐预设；阵营、地图和规则放入默认收起的自定义对战，档案与存档按需展开。有有效存档时首屏保留继续入口。推荐开局使用普通规则，不继承沙盘加成，不改写玩家原沙盘偏好。
- 首次单机不要求先填写昵称；点击联网后再填写，保存呼号接续打开大厅，取消后可返回单机。保留统计说明和已有昵称、战绩与荣誉键。
- 人员共用模型中，突击兵采用头盔、步枪与迷彩；工程师使用蓝灰工装、安全帽和工具箱；间谍保留眼镜和手提箱，使用独立深色外套。近远景保持职责配色，敌我队色独立。
- 方形汉字改成圆角职责标签，保留迷雾、登载、死亡和密集场面隐藏规则。100%易读模式人员为原基准1.7倍、车辆1.35倍，远景封顶2倍／1.5倍；不改碰撞、射程、移动和弹药。
- 地面降低饱和度和细碎反差，加入轻量低通；未接通雷达时不保留大空框，教学仅展示当前一步。横屏切换自动收起指挥面板和教学清单，选择面板按内容缩小。
- 动能短曳光使用细体几何，增强炮口、普通命中和导弹尾迹，保留不同命中类型。生命60%以下才持续冒烟，30%以下加火焰；轻伤不冒烟，维修恢复。
- 全局装饰特效上限为常规72、窄屏／密集40，另为摧毁事件保留12个名额；尾迹总数最多120。显式保留独立科幻渠道目录，避免原版构建切换丢失入口。

## 追加粉丝反馈

- 雷达站替换为宽幅预警阵列，车载防空／反导设备使用较小的相控阵面板，保留原旋转关节，阵面单元合批。原创几何参考设备类别，没有复制截图素材或商标。
- 固定弹道导弹车发射架跟随车体，普通炮塔保留独立瞄准；四发火箭齐射只分开显示弧高，不修改权威命中点或总伤害。
- 装饰树石按放大后的可见半径提前避让，只影响已知单位附近的装饰，不改变障碍、寻路或迷雾规则。
- 舰艉水纹替代圆形烟雾尾迹，随舰艏朝向和船体大小调整；潜航仍不产生水面尾流。现有山脊加强坡面明暗，不宣称增加高地战术规则。
- 飞机气流、舰艇推进与潜艇机械移动声分层合成，保留缓存、移动声类别合并和声道上限；音质偏好仍需玩家试听，未使用或宣称商业交响录音。
- 航母已有3架实体舰载机容量与甲板显示，本轮不虚增展示数量。“五件套”和“取消中国地对空非舰载机”含义尚不明确，不据此删除兵种；武器射程待对局数据支持后再调。
