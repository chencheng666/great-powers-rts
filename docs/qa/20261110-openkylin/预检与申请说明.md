# openKylin 3.1.0 适配申请准备

旧申请提交于2026-10-30，2026-11-10登录个人中心回读为“已取消”。本次以3.1.0重新准备申请，不能将撤回记录当作审核通过或拒绝。

检查openKylin官方3.0 huanghe amd64稳定源时，main及pty索引未找到原Tauri包依赖的libwebkit2gtk-4.1-0。为减少目标系统的依赖障碍，本次采用完整离线H5资源封装标准DEB，以系统默认浏览器运行。没有将WebKitGTK4.0冒充4.1，也不要求用户混装其他发行版源。

包名great-powers-rts，版本3.1.0，Architecture=all；该字段表示不含架构专属机器码，申请验证范围仍仅为openKylin3.0 x86_64。依赖xdg-utils及Firefox/Chromium浏览器，官方稳定源已核对xdg-utils1.1.3-ok1及Firefox125.0.3+build1-ok7.1。源索引摘要在附属JSON中，不等于已在目标系统安装。

文件great-powers-rts_3.1.0_all.deb，共57,245,184字节，SHA256为80d1a97b9b092ed0d8c3973c64385efbc2d95b921ed9f17630f5fcd1a07a3e6e。独立检查DEB/ar/gzip归档、11项文件摘要、权限、应用菜单入口；无维护脚本、服务或内核模块。使用xdg-open替身验证X11/Wayland环境变量下传入固定路径，无图形环境时明确退出；该检查不是Linux桌面实际启动。

实际补充验证环境为macOS26.6.2、Apple M1 Pro、Ego Lite/Chromium。直接打开与DEB内摘要一致的PLAY.html，单机进入、三首音乐切换、保存后重开并读取01:48测试战局通过。5张截图为1200×800，各小于2MB，来自本机浏览器；不标成openKylin实机截图。

报告沿用官方模板，明确openKylin的7组目标用例待执行，并申请社区协助验证。报告及申请人联系方式仅交平台，不作为公开发行附件；公开GitHub附件只放安装包、摘要与说明。没有openKylin测试环境，不能保证一次审核通过，也不填写虚构的目标系统、驱动和测试通过结果。

游戏数据保存在所选浏览器，文件入口固定为/opt/great-powers/PLAY.html。与Tauri、uTools和官网的存储容器不同；旧进度须通过JSON导出/导入，不宣称自动继承。DEB不删除浏览器用户目录，升级、卸载或切换浏览器前仍建议分别备份战局与荣誉。
