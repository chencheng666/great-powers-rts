日期：2026-10-31。网页构建：20261031-fan-bugs6；稳定版本号仍为2.0.2。本轮不替换历史ZIP、桌面安装包和商店包。

来源：《大国崛起bug汇总(6)》共12页及用户关于无桥海战建造能力的补充。文档中的建议作为反馈评估，未执行其中无关操作性指令。

## 本地验证

- `node --test`：602项全部通过，含真实双客户端WebSocket核规则与音效事件、存档验证、战斗/反馈/统计原有回归。
- 新增完整帧测试覆盖两方各六架战机/轰炸机返场、不同机位、补给、存读档和再次出动；同时覆盖满弹手动回指定机场、所有常规地图生产与核存档、反潜鱼雷、四弹伤害预算和关节保留。
- `npm run build` 通过；保留既有Vite大于500KB分块提醒。未宣称本轮解决35MB共享模型库的分区加载问题。
- 构建产物在本地4196端口实际开局：无桥海战开启核规则，部队菜单直升机/常规弹道/反导入口存在；启用核规则后建筑菜单存在发射井。
- 受控场景检查三机停放、起飞尺寸由1/3到1、机场地面/巡航阴影、三种舰艇炮口和反潜器、航母三架实体舰载机；浏览器未捕获脚本异常。
- 390×844触屏布局：页面scrollWidth=390，军种计数可见；大按钮、侧栏与底部指令可用；未以模拟器替代实体手机性能结果。
- 点击后AudioContext为running；音效100%时总线增益为2，试听按钮显示坦克炮声；合成采样非零、有限、有余量，暂停与退出清理由原音效回归覆盖。
- 未完成UOS/openKylin真机验收，本轮不改变商店兼容声明。
