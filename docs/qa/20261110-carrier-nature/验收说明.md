# 3.3.0 航母编队与开源场景细节

构建 `20261110-carrier-nature-r2`。合并先前航母24架候选与用户随后提供的模型资源站建议；先前 `20261110-carrier-airwing-r1` 未部署生产，本轮以本构建发布。

- 保留24架实体舰载编制、6架在外上限、固定机位、逐机起降、一键召回和付费整备。真实飞机自行生产，占部队名额；与旧抽象打击编组互斥。完整模拟验证6架出动后约26.4秒内全部返舰，无人工瞬移。双人/六方协议6/7，旧页面需刷新。
- 自有折翼甲板机增加双发喷口、前翼和起落架，仍按三种材质合批。24机占用、停机布局与飞行数值不变。
- 审阅用户提供的公众号《游戏开发没有模型？别慌！免费3D模型网站大汇总！》，确认其中Kenney与OpenGameArt适用于本项目。核对Kenney官方Nature Kit页面及作者上传包内CC0许可，实际采用rock_largeB、rock_largeD和两种松树的木质部分。原文件、许可、SHA256和转换脚本随仓保存；只提取必要文件，没有把整包330多种模型带入网页。
- 岩石替换为两种可辨轮廓，每件80/85三角形；松树木质几何横置为两种接地倒木，每件50/66三角形。源包树冠风格经实机对照后不直接替换既有写实树冠；未采用试验中的卡通或破碎透明树冠。转换后运行时几何数据20,579字节，不新增大型GLB/贴图请求。
- 新景物共享材质并实例绘制，沿用建筑和部队附近景物清理及迷雾隐藏。Ego Lite实际验证未探索时隐藏、探索后显示、坦克接近后清理。只影响外观，不改变碰撞、寻路、资源及攻击判定。
- 审阅爱给网歼15与CC署名4.0的F/A-18F候选资料。用户随后取消该站登录与下载；未登录爱给网、未下载或采用其模型文件，没有建立该站账号。自有甲板机仍是程序生成模型。

本地验收：684项测试全部通过，包含容量、队列、召回、旧档、几何预算和素材来源摘要。100%与220%视角检查满甲板24架，6架出动后相应显示18架；正常界面起飞按钮使待飞数变24，召回后待飞归零并显示已召回。390×844模拟视口页面宽度390，召回按钮56×56且在可视范围，工具栏可横向滚动。该结果是浏览器模拟，不等同于手机真机验收。

生产已发布构建 `20261110-carrier-nature-r2`，源码 `ea7c00d12bc04f11abec1006409845c0e7a20834`。官网和双人/六方公网回读3.3.0及协议6/7，11个关键页面/资源与本地摘要一致，服务器279项完整资源校验通过，4个保护入口摘要不变。两组共6个SQLite完整性检查通过，备份与线上所有业务表记录数未减少。生产浏览器100%视角显示甲板24架，真实UI起飞后甲板18、在外6/6，召回后待飞0并提示已召回；完整返舰过程已在本地真实Game.update循环验证。试玩后不保存返回并精确恢复5个存档/设置白名单键，未创建联网测试战绩。范围为官网、原版网页与国内双人/六方服务；历史桌面、商店包及独立科幻版保持原版本。
