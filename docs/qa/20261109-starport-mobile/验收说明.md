# 星港演习 3.0.1 触屏界面验收

构建：20261109-scifi-mobile-r4。反馈来源为用户提供的 TapTap 横屏截图。此次仅发布科幻版网页和 H5 包，现代版线上包保持原有版本。

## 改动

- 顶部状态栏压缩至 44px，底部常驻栏 56px，预留宿主胶囊与安全区域；844×390 视口的战场高度从 258px 增加至 290px。
- 未选兵时显示全军、基地、建造、更多；选兵后出现移动、攻击、同型、停止。巡逻、补给、卸载及系统功能收入更多菜单。
- 建造与生产改为按需抽屉，显示进度，进入放置时自动收起；手机横屏、竖屏与旋转时均约束面板边界。
- 空选择提示不再遮挡战场，选中对象显示小卡片，可展开详情；教学默认收起。
- 放置建筑、使用技能或下令时，单指拖动预览落点、松手确认；普通拖图与双指缩放保留。
- 包内 AI 辅助地表纹理继续如实披露，标识明确为“AI合成内容说明”；未接入在线生成功能。
