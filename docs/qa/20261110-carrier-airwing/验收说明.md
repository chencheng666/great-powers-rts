# 3.3.0 航母24架舰载编队

构建`20261110-carrier-airwing-r1`，接续3.2.2，按用户提出的满甲板二三十架飞机方向实现。

- 每舰24架实体舰载机，舰载制空机与舰载攻击机可混编，须由机场自行生产并编入。计入既有部队总上限，不免费附赠24架，不与原3个抽象打击编组叠加。
- 两舷各12个折翼停机位；左舷外伸区加宽，保留24局部单位甲板总长和原航母显示长度。每架飞机保留固定机位，空中出动也占编制容量，返舰后不会挤占其他飞机机位。
- 最多6架所属实体飞机同时在外，剩余逐机排队。只有一架飞机占用滑行/着舰通道，航母移动、断电、近期受击继续限制起降整备。支持一键召回、取消待飞、滑行中沿原路退回、返舰后暂停自动出动，点击起飞可重新出动。战损和耗弹继续付费维修补弹。
- 真实完整模拟发现旧65世界单位进场判定小于喷气机转弯半径；改在180单位内接管2.4秒进场阶段，避免无限绕圈。24机编队出动6架后，完整逐帧模拟中26.4秒内全部返舰，没有把空中飞机瞬移回舰。
- 新增甲板数量、在外/6、待飞与召回状态，独立起飞和召回按钮。敌方快照仅在航母可见时提供停机外观，不发送真实飞机编号、在外编队、任务与弹药信息。
- 旧三机存档按编号补机位，保留原飞机、伤害与任务；新存档校验机位重复、越界及超容量。双人/六方协议升级到6/7，旧页面需刷新，避免旧三机布局客户端连接新规则服务。
- 停机采用自有程序折翼模型，共享几何和材质并参与原军团合批；24架相较空甲板在受控场景增加12次绘制（包含阴影）、6912个三角形。完整世界场景162→174次绘制，不将其等同于所有设备帧率保证。

本地验收：682项测试全部通过，包括完整模拟返舰、24机容量、6机出动限制、固定机位、取消进场、召回权限、权威快照、旧档迁移、起降暂停、自卫、沉没撤离、24架模型甲板边界及互不重叠。Ego Lite100%和220%视角核对24架停机，6架出动后模型相应减少至18；正常游戏界面显示起飞/召回及24/24状态。
