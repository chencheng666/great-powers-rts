# 国产系统适配与应用商店计划

更新时间：2026-10-06；当前交付：v0.3.0 浏览器单机版。

## 已完成与边界

- 玩家反馈银河麒麟可运行原有浏览器版，这是用户反馈，不是本项目对所有麒麟版本和硬件的认证。
- 缺少中文 Speech Synthesis 音色时，改为播放随包内置的 37 条中文 WAV。已有中文音色的设备仍优先使用系统音色；播报出错或超时也会回退。
- 在桌面 Chromium 中模拟无中文音色，验证 WAV 解码、播放、非零音频输出及音量控制。尚未在银河麒麟实机完成此次音频回归。
- 试玩包新增 `启动游戏-Linux.sh` 与 `安装到用户菜单-Linux.sh`，后者仅在用户主动运行时写入用户目录，无需管理员权限。
- 仍由默认浏览器运行，不是原生 DEB/RPM，不包含浏览器运行时，不声称兼容全部 x86、ARM、龙芯或国产 GPU。
- 尚未提交或通过应用商店审核，没有商店链接，不使用“已上架”宣传。

## 实机验收清单

1. 记录麒麟具体版本、CPU 架构、GPU/驱动与浏览器版本，确认 WebGL 2 和硬件加速。
2. 测试基地、远洋战区与子午环阵，记录 30/100/200 单位时的帧率、内存、温度。
3. 断网测试开始游戏、配乐、受袭警报及离线中文播报；分别验证静音、暂停、返回主界面。
4. 验证生产出厂、空军维修、补给车医疗、登陆舰与运输机装卸、无人机跨海。
5. 验证手动/自动保存、刷新、JSON 导出导入、用户菜单启动与更新后存档迁移。
6. 验证中文、全屏、侧栏收起、鼠标框选、右键、不同缩放与 1280/1920/2560 桌面分辨率。
7. 若文件来源限制阻止本地资源、音频或存储，评估正式桌面容器，不要求玩家关闭浏览器安全策略。

## 统信 UOS 与 deepin

CAI 提到 XCPDF 的社区共建与统信上架经历，作为我们的参考方向；该经历来自玩家提供的信息，本项目不据此声称已经获得平台认可。

deepin 官方提供应用商店投递上架指南：开发者注册认证、打包适配、提交与审核。我们会在实机验证后，根据游戏分类、平台和 CPU 架构准备对应包，而不是直接把单个 HTML 当作已合规商店应用。

官方参考：[应用商店投递上架指南](https://www.deepin.org/zh/app-store-submission-listing-guide/)、[应用分发文档](https://docs.deepin.org/info/开发进阶/应用商店/应用分发)。统信 UOS 与 deepin 的具体分发范围、游戏类审核和资质，仍需在平台确认。

## 麒麟与通用上架步骤

官方将麒麟软件商店定位为应用分发平台，相关平台介绍也说明适配完成的软件可以提交上架。具体公开商店接入、包格式、资质和游戏类审核要求需向官方确认，不把私有化平台说明当作完整公开上架流程。

官方参考：[软件仓库与商店](https://www.kylinos.cn/eco/ecoQuery/softwareRepositoy/index.html)、[软件商店平台介绍](https://www.kylinos.cn/productPc/desktop/desktopMarket/)。

1. 由维护者准备开发者账号、主体信息、联系人，确认游戏类应用的实际审核要求。
2. 完成实机适配；按平台确认的要求选择 DEB/RPM 或其他容器，对目标架构分别构建和签名。
3. 准备应用名“大国崛起”、独立图标、简介、实机截图、版本说明、隐私说明、开源与第三方许可、联系方式。
4. 清楚标注原创非官方作品，不使用官方红警商标包装成授权续作；逐项复核 AI 素材、配乐及语音的分发权利。
5. 明确当前无账号登录、无多人联机、无云存档；玩家主动导入/导出文件由浏览器执行，离线包本身不采集战局或上传数据。
6. 完成安全扫描、安装/卸载/升级和数据保存检查后，提交审核；根据审核反馈修订，不提前承诺上架日期。

商店发行与商业化前应另行核对适用的游戏发行、内容、资质和素材授权要求。本文件是工程准备清单，不代替平台审核或法律意见。
