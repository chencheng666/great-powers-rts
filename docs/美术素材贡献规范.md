# 美术素材贡献规范

欢迎用 Blender、PS 等工具共建模型、材质和动画。建议先提交一个单位的前后对比，小批验证后再扩展整个兵种库。

## 优先资产

1. 突击兵、工程师、间谍：先调整身体比例与服装轮廓，保留清楚的职业区别。
2. 攻击无人机：清楚区分机身、传感器、旋翼和武器挂点，保留旋翼轴心与关节。
3. 坦克与车辆：突出车体、炮塔、观瞄和履带，避免细节堆积遮住轮廓。

## 提交内容

- Blender 源文件、GLB、所用贴图及一张游戏战术视角截图；程序化资产保留生成脚本。
- 说明替换的现有模板、三角面数、材质数、贴图尺寸和关节名称。
- 记录素材来源与可分发授权，沿用根目录 `ASSETS.md` 的登记方式。
- 附近景、正常作战缩放与密集编队下的效果，对比帧时间和绘制调用。

## 接入要求

- 沿用目标模板的朝向、尺寸和原点，脚底、轮底或建筑基础贴地，不靠整体下沉遮缝。
- 炮塔、炮管、履带、双腿与旋翼使用现有动画绑定名称和轴心；新增关节须同步说明。
- 金属、玻璃、橡胶与织物材质有区别；敌我识别色独立，不被迷彩、破损或灯光淹没。
- 优先共享材质、合批几何，远处提供简化表现；先从 1K 贴图开始，有实机收益再增大。
- 模型包不依赖运行时外网加载，离线 HTML 与 GLB 打包后均能显示。
