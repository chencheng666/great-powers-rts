# 《大国崛起》2.0「山海防线」规划

日期：2026-10-22。状态：开发中；深蓝试航的本地实现与其余待办分开记录，不是 2.0 上线公告。当前进度见 [开发记录与九战区矩阵](2.0-lifeline-20261022/开发记录.md)。

## 1. 产品定位

主题：守护山海，走向深蓝。

定位：面向喜欢现代装备与策略指挥的玩家，以侦察、运输、后勤、占领和陆海空协同为特色的原创三维 RTS。以国内桌面浏览器为主要体验入口，保留离线单机、现有游客联机与桌面封装，不将移动端作为本阶段验收重点。

「山海防线」先作为 2.0 主题名，不在本阶段擅自更改项目正式名称、仓库、域名或图标。「明日战区」保留为未来月面篇候选，不与现代战场混杂。

现实地理与公开装备资料可作为创作参考，战役、地图、敌我编制与任务采用架空表达。远东采用寒区边境与滨海环境，不将现实城市、居民或现行边界编成应被攻击的目标，不把历史版图直接解释为当前领土主张。图鉴区分现实资料、游戏参数和科幻设定，不宣称军事模拟精度。

核心体验：侦察发现需求 → 护送运输 → 安全卸货 → 港口整备 → 登陆接管 → 建立前哨 → 扩展运输网络。胜利不仅取决于歼敌，还取决于任务完成与资产保存。

## 2. 已有基础与先行核查

以工作区、测试与线上证据为准，不沿用旧路线图中的「尚未发布」结论。最近本轮已核验的发行基线为 1.2.1；开发开始时重新检查当前分支和版本。

已有可复用基础：常规运输收入、陆海空弹药与整备、补给光环、舰艇返港、登陆运输与卸载、工程师接管、四关挑战、存档、战斗复盘、迷雾、双人及六方实验、Three.js 材质与模型预算。

### 3.1 九大战区总表

以下八个主题全部纳入2.0内容范围，加上远东共九个战区。优先级代表开发次序，不代表低优先级可以从需求中删除。阶段候选版可只开放已验收内容，但不能将未完成项宣称为正式2.0九大战区已经齐备。

| 地图／战役 | 场景特点 | 核心玩法与辨识点 |
| --- | --- | --- |
| 海峡风云 | 双岸、大岛、外岛、港口 | 分阶段夺取据点，建立并守住补给通道；重点是跨阶段推进 |
| 列岛守望 | 多座小岛、有限建设空间 | 雷达站、机场、港口有不同价值；重点是多岛取舍与持续争夺 |
| 深蓝生命线 | 大型远海、岛礁、商船航道 | 运输安全抵达才获得主要资源；重点是护航和线路管理 |
| 山口防线 | 山地、河谷、桥梁、高差 | 限量兵力防守、通道争夺、撤退整备与接防 |
| 归航行动 | 海港、居民区、临时集结点 | 保护与分批撤离；运输和保护目标优先于击毁数量 |
| 钢铁走廊 | 工业区、铁路、能源设施 | 占领并修复设施获得收入；破坏过度损害后续收益 |
| 战略警戒 | 大地图、分散战略设施 | 预警、威慑、反制、设施保护；核武器独立可选，默认关闭 |
| 明日·月海基地 | 月表高差、太阳能区、矿区 | 机器人作战、电力与通信网络、就地采矿；独立未来篇 |
| 远东·寒境守望 | 寒区山地、森林、滨海港区 | 运输节点修复、路线选择与寒区接防；独立地域战役 |

每个战区至少交付一张有独特地形与任务循环的可玩地图、一项可独立完成的任务、胜负与重试、存档兼容、复盘及实机素材。不是每个战区首版都开放六方或合作；支持模式必须逐项标注。装备、港口、泊位、占领、资源、任务和复盘尽量共享机制，禁止复制九套难以维护的规则。

### 3.2 模式层次与开发边界

主题战役承担故事与任务变化；遭遇战承担公平对抗；联合行动承担角色分工。连续战役的跨关继承和正式合作协议单独验收，不能把几张独立地图称为已实现连续战役，也不能把六方自由混战称为合作模式。

正式2.0目标为九大战区首版内容与公共机制达标。完整连续战役、全部战区六方开放、复杂铁路调度和额外剧情篇章可留到后续，但须明示边界；若决定缩减正式2.0范围，先由用户确认，不能自行把本表移成无期限愿望清单。

## 4. 战区一：深蓝生命线

场景：原创远海群岛；双方安全起始港、两条可行货运航道、一个有收益但更暴露的中部中转岛。海面为主，岛屿提供建设与侦察空间。普通观察距离能看清航路和岛屿关系，远景缩放和小地图支持跳转。

单机首关建议 15—25 分钟，先完成有限目标的可重试任务；遭遇战版本另设对称起点与资源，不将单机不对称脚本直接搬入竞技。

初始目标：完成规定有效货运、保持至少一个可用接收港并守住任务核心。货运结算量、任务进度与保护目标始终可见。运输被打断先损失收益并提供恢复机会，不因第一艘船沉没立即失败。

资源规则：基础保障收入只够缓慢恢复；海运负责主要发展，空运是较低效率的应急渠道；油井可保留为有限补充。普通战区不再依赖野外矿石采集，月表采矿不受影响。

货运不是按时间直接发钱：货船必须进入有效航线，抵港完成卸货才结算；中断按配置暂停或重置，必须有一致提示。货物不直接变成额外战斗单位。多港共享阵营运输配额，不能靠无限造港复制收入。

玩家能选择接收港、查看下一班与风险、暂停或恢复本方线路，并通过正常舰队指令护航。自动派船具有数量与补发上限，敌军堵口时不能不断制造无意义损失。每条线路状态区分等待、航行、排队、卸货、返航、失效。

地图要素：开放航道、隐蔽但较长的绕行、可接管雷达站、中转港、有限资源点。潮汐与风浪首版仅做视觉，不添加看不懂的随机命中惩罚。

AI 使用同等视野、预算和补给规则，会根据观察到的运输与护航调整兵力；基础难度提供警告和较长恢复窗口，不能读取迷雾中的船位精准伏击。

## 5. 港口维修与运输接驳

港口至少区分货运卸载区、舰艇整备区与登陆卸载区。泊位是有上限的服务位置，不共用一个目标点。外海等待点与进出航道避免相互穿越。

维修按「请求 → 分配泊位 → 接近 → 停稳 → 维修补弹 → 离港」执行。包括水面舰艇与潜艇；潜艇使用清晰的整备状态，不在水下悄悄获得无限补给。受击后是否暂停须有公开规则，不允许无限免费战斗回血。

提供手动返港与可选自动低血低弹返港；阈值、开关和当前原因可见。默认不擅自覆盖玩家刚发出的明确战斗命令，不追逐任意移动舰艇维修。用户取消、目标港摧毁、断电、资金不足和所有泊位繁忙均有明确后续行为。

维修有费用、速率和每港服务上限；同舰不重复占位、不因多个光环叠加超额回血。无钱不出现负数，任务撤销及时释放泊位。保留合理基础补给窗口，避免全局弹药耗尽导致双方无法继续。

港口被毁或易主：原任务取消或改派合法友港；船舶货物与载员归属不随港口自动转移；货运只能对合法货主结算一次。不能把船强行传送到另一泊位。

## 6. 战区二：列岛守望

场景：原创列岛，建议两座起始岛、两座侧翼资源岛、一座中央枢纽岛。没有陆桥，登陆是必要选择；每座可争夺岛均有合法上下岸区域，拒绝「全岸可走、实际处处卡船」。

单机任务链：侦察候选登陆区 → 装载人员与车辆 → 护送并安全卸载 → 接管岸上设施 → 守住接管窗口 → 恢复港口供电 → 接入货运 → 建立下一段前哨。

遭遇战主目标采用据点积分或连续控制，不强制全歼；保留次要设施争夺。正式时长和占领时间经试玩确定，画面显示争夺、暂停、衰减与得分原因。

占领条件：指定可占领设施有标识、范围、允许单位和工程师要求。敌我同时在场时进入争夺，不重复跳归属；同类型单位数量带来的加速有上限，不能人海瞬间接管。首版优先复用既有工程师接管，避免同时新增多套互不一致规则。

岛屿占领不等于自动持续收益：港口或补给节点须完整、通电并接入可行运输线。被摧毁可维修恢复，不能第一次破坏后永久软锁主线。失守后按一致的争夺规则夺回，不让工程师所有权与岛屿积分冲突。

登陆舰载量沿用统一单位占格；装载中、航行中、卸载中有独立状态。卸载前验证地面可通行空间，逐个寻找合法位置；容量不足、拥堵或岸线不可用时说明原因并可取消，不重叠生成或穿过山体。

首版不加入无提示水雷、随机天灾和大量一次性脚本兵种。地图空间应容纳绕行和反制，起始港不能在敌方初始射程内。

## 7. 战区三：远东·寒境守望

场景：架空远东寒区边境与滨海地带，使用原创地名。元素包含针叶林、山口、河流、桥梁、铁路货场和不冻港风格设施。不是现实作战方案，不使用真实设施坐标、攻击路线或「收复某现实城市」的表述。

定位：区别于海图的「有限通道与持续保障」战场，不再做一张大平原换白色地面。初期以港口和公路运输衔接陆战，铁路先做地图与占领节点，不承诺完整列车调度。

首关「北境归航」：保护运输编队通过两个补给节点，修复中转站并抵达港区；允许选择较短暴露通道或较长侧路，失败原因与补救手段可见。

扩展关「山口接力」：守住通信与物资节点，安排分批撤退、整备与接防。胜利评价包含运抵物资、保全部队、基础设施完好度，不只计算歼敌。

寒区规则首版：交通条件与道路通行区可视、固定且对双方一致；天气仅影响表现。后续才评估公开、可预警的天气事件，不引入无反制随机冻坏装备。民用建筑不产生攻击奖励，不以破坏居民区获得额外积分。

### 7.1 海峡风云：阶段推进战役

地图结构：双岸与一座纵深大岛，外岛承担观察、中转与备用登陆功能；不使用真实地名和现实登陆路线。不同于列岛的并行积分争夺，本战区强调「立足 → 接通运输 → 稳定前哨 → 推进最终任务」的顺序。

阶段完成条件必须包含补给和驻守，不是工程师触碰一次即永久解锁。前哨失守会影响后续资源，但提供备用接收点与恢复手段，不让唯一桥头设施被毁后游戏无限持续却无法完成。

首关以保障运输并接管通信枢纽为最终任务，不强制全歼。验收包含阶段读档、前哨失守、换线恢复、跨岸运输及完整胜负；不把镜头切换或剧情演出当成阶段逻辑。

### 7.2 山口防线：有限兵力与接防

地图结构：主山口、侧翼河谷、至少两个合法通道和后方整备区。高差与遮挡规则须公开一致；若尚无高地视野机制，不在文案中宣称存在高地加成。桥梁先保证可靠通行，可破坏和修复另做完整规则后才启用。

首关给固定编队与有限增援，玩家在已预警的分批压力下守住通道，并把受损部队撤到整备区，安排轮换。通道变更、增援到达与任务倒计时均可定位，不靠无提示出生敌军制造难度。

与远东区别：山口防线是通用地形战术挑战，远东是寒区运输战役。验收必须证明不依靠无限生产也能完成接防，并覆盖补给不足、撤退受阻、备用通道、波次读档和失败重试。

### 7.3 归航行动：保护与撤离

地图结构：受威胁港区、居民区、集结点和撤离出口。居民与救援目标不作为可获奖励的攻击对象，以抽象受保护目标与可读登乘表现呈现，不加入血腥内容。

任务流程：抵达集结点 → 保持安全装载窗口 → 运送至有效撤离出口 → 运输平台返场或整备 → 完成下一批。每批有唯一身份，装载、卸载、撤离与损失只结算一次。不得通过来回上下车刷新人数或奖励。

单机首版可配友方AI，明确友方控制与碰撞规则。后续两至四人合作需实现真正的队伍、共享任务、保护目标权限和掉线接管，不能借用现有自由混战假充合作。胜利以保护和撤离为主，禁止通过全歼绕过核心任务。验收包含满载运输损失、部分成功、出口失效、重新装载与存档恢复。

### 7.4 钢铁走廊：工业修复经济

地图结构：工业区、能源节点、货运站与连接道路。铁路初期表达工业布局及物流节点，不提供尚未实现的列车运输收益或动画承诺。

资源循环：接管设施 → 工程修复 → 接通电力与运输 → 恢复有限产出。设施完整度影响公开的生产效率；争夺时停产，归属稳定且条件恢复后继续。生产有配额和上限，不能靠反复易主或维修刷奖励。

破坏可以阻断敌方经济，但也降低夺取后的可用价值；允许修复，避免不可逆的全图经济枯竭。工业收入与海空货运按模式配置，不能无意叠加使资源失衡。验收包含同时断电断路、修复取消、工程师损失、归属切换、资源上限及旧运输模式回归。

### 7.5 战略警戒：预警与分散保障

复用已有战略纵深与可选战略威慑首版，先核对已经实现的门槛、冷却、有限次数、预警、友伤、反导依赖及存档规则，不重新复制一套。可在现有地图精修并增加任务变化，不要求仅为数量再造一张空旷大图。

常规模式也必须独立可玩，目标为保障分散设施、恢复预警与维持任务节点。核规则默认关闭，房间展示且所有玩家确认后才启用；任何新增战略玩法都需对应提前发现、主动干扰、分散保存或有限拦截等可读反制，不能设计必胜按钮。

不采用现实武器使用程序或宣称真实毁伤。验收覆盖关闭核规则、断电、预警交互、反制失败与成功、隐藏情报过滤、重复指令及联机一致性。策略数值以游戏平衡为准。

### 7.6 明日·月海基地：未来能源网络

独立未来篇，复用既有子午/月表资产，重做有辨识度的陨坑、山脊、太阳能区与矿区布局，不能沿用现代地面换色。士兵槽位在该规则中采用机器人编组，对应图鉴、动作、维修与补给统一适配，不更改全部现代地图的人类单位。

核心循环：机器人采集 → 发电与储能 → 中继覆盖 → 建造与维修 → 扩展采集区。明确能源和资金的边界，断开中继只影响公开规定的远端生产/整备效率或需中继的能力，不强制禁止玩家所有基本指令；可修复重联，避免断电即永久锁局。

首版采用固定光照与可预期能源预算，不同步加入复杂轨道、真实月昼周期、氧气或食物系统。机器人使用电力整备，弹药型装备仍消耗对应补给，不能借电力获得无限火力。未来武器有明确角色与反制，不直接压制现代竞技地图。

验收包含能源收支、断线提示、储能耗尽与恢复、机器人维修、矿区争夺、网络读档以及不同画质下地形/轮廓可读性；不宣称真实月球环境模拟。

## 8. 美术与建模同时交付

统一风格：现代写实感的三维 RTS，而非追求不受性能限制的近景电影模型。保持可识别轮廓、约45度可读视角、实体接地阴影，避免地面发白、装备与地图同色和一片纯黑。

| 对象 | 本阶段要求 |
| --- | --- |
| 集装箱船 | 船桥、分层船壳、集装箱组合、吃水与尾流；正确卸货状态，不能悬空或穿码头 |
| 登陆舰 | 可读的跳板与车辆甲板、实际载员表现、靠岸接触；保留远近细节预算 |
| 港口 | 码头、护舷、泊位标识、维修设施、装卸机械；出入口与服务位置对应 |
| 岛屿 | 岩岸、浅滩、沙滩、植被、地形层次；视觉岸线与碰撞能对应，不能只用纹理假装可登陆 |
| 现代建筑 | 体块、屋顶设备、混凝土和金属分层、合理比例；基座清晰但不覆盖整个场景 |
| 远东环境 | 冷暖分层、针叶林、岩面与局部积雪，地面不泛白；统一太阳与环境光方向 |
| 海峡与山口 | 双岸与纵深层次、岩壁河谷、桥面与坡道接地；避免唯一通道拥堵和假高差 |
| 救援与工业区 | 集结区、疏散标记、厂房管线与能源设施；保护目标和可接管设施容易分辨 |
| 战略与月面 | 分散设施的工作状态、雷达/反导动画；月表陨坑、机器人与能源中继结构，不用同一模型只换颜色 |

优先精修集装箱船、登陆舰、港口三个反复出镜对象，再做护航舰与远东补给站。不同时新增一批只有名称差异的武器。材质优先共享贴图、图集与法线粗糙度，限制透明层、独立材质数量和实时光源。

每个战区交付全景、正常指挥距离、任务关键交互和重点模型近景；海战另交港口、满载登陆舰与运输画面，陆地/月面交相应整备、工业或能源节点画面。全部来自本次实际引擎。截图注明受控场景，不用概念图充当可玩效果。素材使用原创、项目既有或授权明确资源，记录来源。

## 9. 交互、复盘与成长

港口悬浮信息包含工作状态、泊位、排队、维修成本及阻塞原因。选中运输单位显示载量、货主、目的地与任务阶段；只展示本方或已获知信息。小地图区分货运、战斗运输、争夺与受袭，避免所有标记同色。

任务目标能定位，航路可显示与隐藏；移动、排队和卸载引导线风格统一，不让大量线条遮住战场。警报按事件去重、冷却，中文语音不能连续刷屏。

复盘增加运输抵达/损失、运抵价值、维修/补弹支出、登陆成功与损失、占领持续时间和关键节点变化；注明事件记录上限，不称为完整录像。

挑战星级优先评价目标、损失与用时，成绩与普通荣誉分离。称号和徽章只提供展示价值，不给联机战斗属性加成。旧进度、导入导出与成绩去重保持兼容。

## 10. 公平、存档与联网

所有运输生成、货物结算、修复、补弹、装卸和占领由模拟核心判定；联网时服务端权威，页面动画不修改资源或归属。

数据需覆盖货运批次唯一标识、阶段、归属、航线、泊位占用、等待队列、载员、占领进度和任务计时。读档与重连不能重复结算、复制货物、丢载员或永久占泊位；旧存档采用显式默认值与迁移，不静默覆盖损坏内容。

新增模式先单机闭环，再做双人对称规则；六方必须独立检查席位、资源、出生点、敌我重排、泊位与视野过滤，未通过前在界面限制而不是默认为兼容。不借本次开发加入未经实现的3v3、排位或微信登录。

## 11. 分阶段验收

| 阶段 | 必须证明的结果 |
| --- | --- |
| 0：核对 | 当前代码状态、已有测试、存档协议与实际可复现问题清单，说明复用和必要改动 |
| 1：深蓝最小闭环 | 正常抵港结算、截击损失、队列等待、维修补弹、港毁改派、资金不足恢复、胜负与重试均可实际操作 |
| 2：列岛闭环 | 满载航行、合法逐个卸载、接管与争夺、供电恢复、货运接入、失守夺回与不可达位置提示 |
| 3：远东 | 一条可完成的运输任务、两个有意义的路线选择、节点修复和清晰结算，不只换雪景 |
| 4：海峡与山口 | 跨阶段补给推进、前哨恢复，以及有限编队接防；两者均独立通关与失败重试 |
| 5：归航与工业 | 分批撤离结算正确、保护目标规则完整；工业接管修复、能源物流与产出闭环 |
| 6：战略与月面 | 既有威慑回归和新保护任务、纯常规可玩；机器人采集、能源通信、断线恢复闭环 |
| 7：联网与性能 | 各阶段持续回归，最终进行真实双客户端及获准开放的六席验证；合作另验；标准/高画质与大军团测量 |
| 8：发行候选 | 九战区支持模式与完成清单核对、阻断缺陷清零、文档截图更新、源码/包/国内服务器版本一致、完整下载校验与回退可用 |

必要自动测试：重复结算、多个港口刷收益、零资金、断电、同时入港、取消任务、返港遇堵、船或港被毁/易主、装卸过程中存读档、无效岸点、争夺暂停、越权指令、迷雾泄露及多席归属。

各战区补充测试：阶段推进与回退、预警波次重放、撤离去重、保护目标权限、工业归属与收入、能源网络断连与恢复、机器人模式迁移、关闭核规则。九战区分别记录「未开始/开发中/待验收/已通过」和支持模式，复用旧地图不能自动把新任务记为已通过。

必要手动测试：正常桌面浏览器从菜单进入到通关；不借调试接口改钱或改任务状态；加载中与失败提示；1680×1050、1920×1080和1280×720布局；新旧存档备份与恢复。

性能记录：相同设备、分辨率、画质与视角下测120/240单位，包含舰船、运输及岸上部队；固定热身与采样时长，记录帧时间P50/P95、绘制批次、三角面、可获得的内存指标与联网流量。后台节流数据不得用于帧率结论；先建立基线，再定约定设备上的目标，不能以截图非空代替性能达标。
