# 玩家统计与指挥官沙盘更新

## 功能与边界

- 鉴权后台 `/admin/`：北京时间按日访客、昵称进入、游玩人数和有效时长曲线；时长区间、30/60分钟累计人数、玩家分页/搜索、可选同名归并、CSV、UA/浏览器/系统/设备、版本、模式/战区、当前在线、新老玩家、成熟队列次日及第7日返玩率、错误分类。
- 昵称是玩家自填呼号。同名默认独立档案；归并按昵称显示成员数，不推断实名身份。不保存IP。历史双人联网账号展示与新统计分开，UA和历史时长不回补。
- 前台、未暂停且非观战才累计；15秒心跳。服务端限制累计增量、断线最多45秒，重复/乱序去重、多标签页取时间并集、跨北京时间午夜分摊。离线文件不采集。统计从部署启用后开始。
- 指挥官沙盘：同一次打开页面累计有效游玩120分钟解锁，本机保存解锁状态；刷新前未解锁进度不保留。达到阈值只提示，不自动启用。联机仅提示奖励解锁，设置仅适用于普通双阵营单机。
- 起始资金5万/10万/100万；造兵和建筑2倍/3倍；可选无限弹药。只增强我方，不改变射速、维修、机体或舰载机损失、机器人电量。应用当前局只补足资金；切换倍率保持已付费用/进度比例。存档保留沙盘标记，结算不计正常荣誉或挑战成绩，统计单列沙盘模式。
- 游戏主页、官网醒目展示《司马法·仁本》警句；背景改为12秒海陆空受控实机剪辑，1280×720静音，约2.2MB。支持暂停、后台/战局自动暂停、减少动态效果/省流静态封面、加载失败回退；离线内置视频。素材沿用项目既有模型授权，见ASSETS.md。
- 此次更新网页和免安装离线包；现有9种原生桌面安装包保留原v2.0.0，不声称已重建。
